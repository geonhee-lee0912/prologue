# 스며드는 색의 범위와 농도 비교

## 범위 100%에서 질감 비교

[A와 B를 나란히 보기](prologue-diffuse-wash.html) · [B 단독 이미지](wash-pencil-b.png)

A는 선택한 ②번의 범위 100%, 농도 125% 화면이다. B는 같은 코랄·하늘색 그라데이션과 중앙 로고에 처음 색연필 원본의 획을 입혔다. 원본에서 넓은 명암을 제거해 만든 회색 질감만 겹치므로 흰 여백으로 갈수록 획도 사라진다. 실제 앱에 적용할 질감은 검토 중이다.

## 이전 ②번 범위 조절 기록

- [②번 범위 조절 화면 캡처](2026-11-07-wash-selected-2-editor.png)
- [범위 100%의 ②번 이미지](2026-11-07-wash-selected-2.png)

범위는 기존 조절기와 같은 85~115% 안에서 움직이며 100%에서 시작한다. ②번 고유의 넓은 범위 계수는 유지하고 전체 조절기 값만 낮췄다. 농도는 이전 전체 농도 125%에 고정했다. 색·로고·코드로 만든 미세한 결은 유지한다.

기록용 세 안 화면에서 ②번을 범위 100%·농도 125%로 설정한 그라데이션과 현재 화면이 같음을 실제 브라우저에서 확인했다. 화면 한 개·범위 입력 한 개, 조절 양 끝과 100% 복귀, 같은 화면/로고 크기, PC와 휴대폰 390·320 폭에서 잘림과 오류 없음을 확인했다. 이미지 생성이나 비용은 없다.

## 세 안 비교 당시의 조절과 확인

상단의 전체 범위·전체 농도는 세 안에 공통으로 적용된다. 각 안의 상대적인 차이는 유지한다. 미세한 결은 켜고 끌 수 있으며 ‘초기값’으로 원래 비교 조건에 돌아간다.

PC에서 세 화면을 나란히, 휴대폰에서 가로로 넘겨 볼 수 있다. 각 화면은 390×844, 같은 먹색 로고는 196×54로 표시했다. 로고 세 개의 로딩, 범위·농도 변경, 결 켜기/끄기, 초기화와 PC·휴대폰 배치, 화면 오류 없음을 확인했다. 실제 앱 A01은 이번 비교에서 바꾸지 않았다.

시각 검토 의견 — ②는 짧은 첫 화면에서 색이 더 넓게 느껴지면서 중앙 여백을 유지해 추천한다. ①은 더 절제돼 있고 ③은 모서리 색이 조금 더 분명하다. 운영자의 최종 선택에 맞춰 적용 범위를 의논한다.

## 범위·농도 최댓값 내보내기

운영자 요청으로 전체 범위 115%, 전체 농도 125%인 조절기 최댓값을 적용해 세 안을 각각 저장했다. 미세한 결은 켜진 상태이며 각 안의 원래 상대 차이는 유지했다. 두 값이 실제 입력의 최댓값과 같음을 촬영 전에 확인했다. 화면과 로고의 논리 크기는 그대로이고 픽셀 밀도 두 배로 내보냈다. 비교 화면의 초기값과 기존 앱은 바꾸지 않았다. 이미지 생성 비용은 없다.
