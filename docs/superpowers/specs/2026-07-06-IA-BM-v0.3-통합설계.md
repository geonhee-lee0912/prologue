## 1. 탭 구조 v0.3 (5탭, "안 Y")

```
[1 추천]   [2 이야기]   [3 이어짐]   [4 활동]   [5 마이]
```
*(탭 이름은 전부 가칭 — 카피 패스 별도)*

| 탭 | 정체성 | 핵심 내용 | 과금 표면 | v0.2 대비 |
|---|---|---|---|---|
| **1 추천** | 오늘의 큐레이션 | 오늘 추천 **2장 중 택1** (§4) | 추가 추천권 | 카드 메커니즘 변경 |
| **2 이야기** | 순수 무료 피드 (성역) | 익명 이야기 조각 피드, 긍정 반응만, 상호 반응 시 신원 공개 | **무과금 성역** | "이야기 반응"→"이야기", 상품 분리 |
| **3 이어짐** | 관심~대화 한 퍼널 | 받은 관심 / 대화 중 / 보낸 관심 섹션 스택 (§3) | 대화 연장만 | **관심탭+대화탭 병합 (신규)** |

## 2. TAB-4 "활동" — 확장 가능한 수익 선반

상품이 아니라 **선반**을 설계한다. 참여형 경험 상품이 이 탭으로 계속 들어오고 나간다. IA를 바꾸지 않고 새 고ARPU 상품을 실험할 수 있는 수익 표면 — BM 재무 검증의 "매출 레버가 유저 수 하나뿐" 리스크에 대한 구조적 답.

**입점 5조건 (경사로 방지):**
1. 파는 것이 **"풀 접근"이 아니라 "활동 형식"**일 것 — 상시/기간제 무관. (기존 "기간 한정 이벤트만" 조건을 이걸로 대체)
2. 참가자의 **상대 풀은 언제나 전체 무료 풀과 동일** (참가가 기본 루프를 대체하지 않음)
3. **속성 필터형 접근권 영구 금지** (직업별·고소득 라운드 등)
4. 만남 보장 아님 결제 전 명시, 미성립 시 **전액 환불 기본**
5. 쿨다운·비상품화·결핍자극 금지 원칙 그대로 적용

**입주 예정 상품:**
- 지금: **이야기 라운드** (2주 글 기반 유료 코호트, 24~32명 성비 균형 → 익명 열람·반응 → 익명 문답 → 상호 선택 시 공개 → 7일 대화방 합류). 2년차(수도권 임계 도달 후) 출시.
- 나중: **로테이션 소개팅**(실시간형), 상시 글쓰기 살롱·테마 코너 등.

**상시 허용 결정:** "활동 형식을 상시로, 풀은 개방" → 상시 살롱·챌린지는 열되, "상시 프리미엄 회원 풀"(Trust Plus 부활)은 조건 1·3으로 차단.

## 3. TAB-3 "이어짐" — 관심+대화 병합

관심과 대화는 끊긴 둘이 아니라 `관심→상호→매칭→대화`의 연속선. 저볼륨(무료 추천 소량)이라 분리하면 각 탭이 휑해짐. 하나로 모아 **상태 승격**으로 연출.

**섹션 스택 (한 스크롤):**
```
① 새로 받은 관심   ← 결정 대기 (맨 위, 행동 필요)
② 대화 중          ← 매칭 진행 중 방 목록 (중앙, 핵심)
③ 보낸 관심        ← 상대 응답 대기 (맨 아래, 조용히)
```
- 매칭 성사 시 ①의 카드가 ②로 올라가는 연출 = "첫문장이 이어졌어요".
- **대화방은 탭이 아니라 목록 위에 뜨는 전체화면** (카카오톡 = 목록 탭 + 방 화면 구조). 대화 중엔 탭 바 숨김. 이래야 "한 탭에 관심·대화 섞여 정신없음" 문제가 안 생김.

## 4. 추천 메커니즘 — "2장 중 택1"

무료 기본 추천을 **하루 2장 제공, 사용자가 택1**. (기존 "하루 1장" vs "하루 3장" 문서 충돌을 이 형태로 해소)

**왜 단일 1장이 아니라 2장 택1인가:**
- 단일 카드는 수동적(예/아니오). 둘 중 고르면 **능동성**이 생겨 지루함·수동성 완화. 읽을거리도 2배 → "휑함" 걱정 완화.
- 그러면서 결과물(관심)은 여전히 큐레이션된 소량. 볼륨 자체는 2번 탭(이야기 피드)이 담당.

**"택1"의 정확한 의미:** 두 이야기를 **모두 열람 가능**, 하루 관심은 **최대 1명**에게. 선택 = 관심 투자처.
- 두 사람 모두 이야기가 읽힘 → 존엄 유지, "버려지는 후보" 없음.
- 안 고른 쪽엔 **아무 신호도 안 감. 거절 아님. 나중에 다시 등장 가능** → "진 사람" 없음.

**얼굴 대결 차단 (CONCEPT-2 준수):** 2장을 나란히 놓는 비교는 자칫 "더 예쁜 쪽 고르기"(hot-or-not)가 됨. 이를 막는 장치가 §5 책 표지.

**공급 주의:** 2장은 하루 2후보 품질 통과 필요 → 초기 저밀도에선 부담. 억지 추천 금지 원칙상 후보 부족 시 1장 또는 빈 상태 허용. 3~5장보다는 훨씬 감당 가능.

## 5. 카드 = 책 (BOOK-1 표지 정의 변경)

**변경:** 기존 IA v0.2 "표지 = 대표사진 + 한 줄" → **"표지 = 사용자가 쓴 한 줄 제목 (+최소 메타), 사진은 내지(펼치면 나옴)".**

**표지 (2장 택1 화면에서 비교되는 면):**
- 사용자가 직접 쓴 **한 줄 책 제목** — 자기소개형("느긋한 주말을 좋아하는 개발자입니다")도, 시적/뜬금없는 제목("목요일 오후 3시의 커피")도 허용.
- 최소 메타: 나이·지역·인증 배지.
- **얼굴 없음.** 진짜 책 표지처럼 타이포 중심 + 색/질감. → 2장의 비교 축이 얼굴이 아니라 **제목=이야기**가 됨.

**펼치기 (책 열람):**
- 페이지를 넘기며 **사진 여러 장 + 텍스트(나의 프롤로그·이야기의 목차·관계의 문체)가 교차**.
- 사진은 여기서 온전히 봄 → "사진을 뒤로 미루지 않는다"(사용자 조건) 충족하되, 표지 헤드라인은 아님.

**부수 효과:**
- 제목이 **필수 입력** → 긴 자기소개는 막막해도 "한 줄 제목"은 부담이 적어 **글쓰기의 가벼운 온램프**가 됨. "사람들이 글을 쓸까" 우려에 대한 부분적 답.
- 제목 검수 부담(연락처·부적절 표현 삽입 가능) → 1인 검수 큐에 제목 포함, 자동 필터 필요.

## 6. 재화(충전형) 결제 시스템

전 상품을 **내부 유료 재화 충전 후 사용**으로 전환. (기존 "원화 단품"에서 변경) 근거: 한국 진지 계열의 검증된 과금 형태(커피한잔 "커피콩", 아만다 하트)이고, 웹 충전소 전략과 시너지(충전만 웹으로 빼면 상품별 결제를 매번 안 해도 됨), 구독 없는 단품 체계의 자연스러운 결제 레일.

**적용 범위:** 전 상품 재화화 (라운드 포함). 결제 시스템 하나, UX 일관.

**클린 설계 원칙 (재화 다크패턴 회피 = 브랜드 자산):**
| 통상 다크패턴 | 프롤로그 |
|---|---|
| 애매한 환율로 원화 감각 흐리기 | **환율 투명 고정 + 원화 상시 병기** |
| 잔액 어중간하게 남기기(breakage) | 상품 가격을 충전 단위와 딱 떨어지게 |
| 큰 충전 보너스로 과충전 유도 | 보너스 없음 또는 최소, 과충전 유도 카피 금지 |
| 짧은 유효기간 | 무만료(또는 법정 최장), **미사용 잔액 환불 가능** |

**미결정:** 재화 이름(책 메타포 후보: 잉크·활자·페이지 등), 환율(예: 1재화=1,000원), 충전 팩 구성, 상품별 재화 가격 — **다음 세션 안건(§8).**

## 8. 열린 결정 (다음 세션 안건)

1. **가격**: 재화 환율, 충전 팩 구성, 상품별 재화 가격. 논의 중이던 방향 — 접근성 상품(추천권·연장)은 낮게, 자기 산출물(공방·리포트)·경험(라운드)은 높게 ("가치 차등"). 재무 검증 지적(부가세·수수료 현실화) 반영.
2. **재화 이름** (책 메타포 후보).
3. 인증 금지 항목 — 사용자가 수정 희망 표명(연봉·자산·학벌 금지 범위 재검토). **미착수.**
4. 탭 최종 이름 카피.
5. 이 문서 결정을 반영해 기존 문서 갱신: IA v0.2, BM v0.2 제안, 그리고 공식 08_화면목록_IA.
6. 카드/책 펼쳐보기·택1 화면 상세 UX (원래 후속 패스 범위).
