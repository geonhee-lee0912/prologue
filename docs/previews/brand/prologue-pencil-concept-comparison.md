# 스플래시 ‘이야기가 스며드는 첫 장’ 비교 제작안

상태 — 운영자가 디자인의 이유를 먼저 정하고 시안으로 비교하는 방향에 동의했고, 이번 라운드의 모델·프롬프트·수량·견적을 확인해 세 장의 생성을 승인했다. 세 안 모두 생성 완료했고 같은 원본 로고와 흰 바탕으로 합성했다. 아래 세 구도는 비교 제안이며 최종 선택이 아니다. 기존 앱 A01의 배치는 바꾸지 않았다.

시각 검토 의견 — A는 아래쪽에 넓게 이어지는 색과 중앙 여백의 균형이 가장 안정적이라 추천한다. B는 절제돼 있지만 흔적이 작게 느껴진다. C는 두 흐름의 차이가 드러나며 아래를 감싸는 곡선의 인상도 강하다. 의미가 사용자에게 전달되는지는 이 제작 결과만으로 확인한 사실이 아니며 운영자와 검토한다.

## 비교 기준

- 컨셉: 첫 장의 여백에 나의 이야기가 조금씩 스며든다.
- 같은 먹색 Prologue 원본, 같은 로고 크기와 중앙 위치, 흰 바탕, 연한 피치·코랄을 유지한다.
- 로고는 실제 자산으로 별도 합성한다. 배경에 글자를 생성하지 않는다.
- 세 안의 차이는 획의 밀도·방향·범위·겹침이다. 굵은 입자를 확대하는 대신 가는 연필 획으로 제작한다.
- 휴대폰 화면을 같은 크기로 나란히 비교하고, 추천안은 아래에서 넓게 스며드는 A다. 흰 첫 장의 여백을 유지하면서 따뜻한 결을 알아보기 쉽다는 이유다.
- 비교 후 선택한 안을 기존 앱 A01에 반영한다. 현재 앱은 직전에 검토한 확대 배치를 유지한다.

| 안 | 구성 | 의미 |
| --- | --- | --- |
| A | 아래에서 스며드는 첫 장 | 흰 첫 장을 가장 넓게 남기고 아래쪽에 온기를 더한다. |
| B | 여백에 쌓이는 기록 | 페이지의 옆 여백을 따라 짧은 흔적이 쌓여, 대화의 축적을 표현한다. |
| C | 두 이야기가 만나는 겹침 | 서로 다른 두 사람의 이야기가 만나 첫 장이 시작된다는 의미를 담는다. |

## 생성 설정

- 서비스·모델: 힉스필드 GPT Image 2.6 (`gpt_image_2_6`)
- 수량: 서로 다른 구성의 PNG 각 한 장, 총 세 장
- 공통 설정: 9:16, 1k, high, 실제 알파 투명 배경
- 참조 이미지: 없음. 기존 먹색 로고는 생성 후 별도 합성한다.
- 비용: 이번 라운드의 실시간 견적을 대화에서 알리고 승인받는다.

## 공통 프롬프트

용도: Prologue 모바일 앱 스플래시에 사용할 색연필 질감 배경 자산. ‘첫 장의 여백에 나의 이야기가 조금씩 스며든다’가 시각 컨셉이다.
9:16 세로 캔버스의 실제 알파 투명 PNG. 앱에서 흰 바탕과 먹색 Prologue 워드마크를 별도로 합성하므로 이미지에 글자·로고를 넣지 않는다. 화면 정중앙과 위쪽은 완전히 투명한 여백으로 남긴다.
스타일: 성인을 위한 모던하고 단정한 편집 디자인. 가늘고 짧은 색연필 획을 여러 번 겹친 마른 연필 결. 입자 크기는 작고 섬세하며 획 사이로 투명 공간이 보인다. 넓은 영역에도 커다란 알갱이나 반복 무늬가 나타나지 않게 한다.
팔레트: 흰색을 많이 섞은 매우 연한 피치·코랄 #F4D3C8와 #FAEAE3. 진한 코랄 #C8603C는 사용하지 않는다. 가장 색이 많은 부분도 연한 파스텔이며, 색이 적은 방향으로 획의 밀도가 줄어 실제 투명으로 사라진다.
제약: 종이 사각형·바깥 테두리·책·편지·비행기·하트·인물·연필 도구·사진·목업·그림자·입체 효과·글자·문장·워터마크 없이 추상적인 색연필 흔적만. 수채화 번짐·구름 같은 덩어리·디지털 블러·매끄러운 벡터 그라데이션·색면의 딱딱한 경계·새로운 색상은 피한다. 색이 없는 영역에는 종이 질감을 채우지 않는다.

## A — 아래에서 스며드는 첫 장

구성 A: 색연필 결은 화면 아래 30%에만 배치한다. 가는 획들은 주로 수평으로, 아주 완만하게 오른쪽 위로 향한다. 아래 가장자리 바깥에서 넓게 이어지고 왼쪽 아래가 조금 더 조밀하다. 아래 전체 너비에 걸쳐 희미하게 보이며, 위로 갈수록 획이 성기게 끊어져 사라진다. 가장 높은 흔적도 화면 높이의 아래 35% 안에서 끝난다. 산이나 구릉의 윤곽선처럼 단단한 외곽 형태를 만들지 않는다.

## B — 여백에 쌓이는 기록

구성 B: 왼쪽 가장자리의 아래 절반에 짧고 가는 색연필 획을 성기게 쌓는다. 획은 주로 수평이며 길이가 서로 다르고, 왼쪽 가장자리 밖에서 화면 안쪽으로 조금씩 들어온다. 가장 넓은 부분도 화면 너비의 22% 안에서 끝나며 중앙에는 닿지 않는다. 아래쪽이 조금 더 조밀하고 위쪽과 오른쪽으로 갈수록 획이 줄어든다. 세로로 곧게 자른 색 띠나 외곽선 없이 비정형의 가볍고 조용한 여백 흔적으로 그린다.

## C — 두 이야기가 만나는 겹침

구성 C: 화면 아래 30%에서 왼쪽 아래와 오른쪽 아래에 각각 연한 색연필 흐름이 하나씩 시작된다. 둘은 같은 연한 피치·코랄 계열이되 오른쪽은 조금 더 옅다. 두 흐름이 아래 중앙에서 비대칭으로 느슨하게 겹친다. 각 흐름은 가느다란 여러 획의 집합이며, 두 덩어리·하트·V자·날개·인물처럼 보이지 않게 한다. 겹친 부분도 진해지지 않으며 위로 성기게 사라진다. 화면 중앙 로고 영역은 완전히 투명하게 남긴다.

각 안의 실제 요청 프롬프트는 공통 프롬프트에 해당 구성 문단을 이어 붙인 전체다.
