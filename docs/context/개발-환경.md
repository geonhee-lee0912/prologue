# 개발 환경

이 저장소에서 일할 때 필요한 컴퓨터·계정 설정과 에이전트 실행 규칙이다. 비밀값은 적지 않는다. 2026-10-15 프롤로그 컴퓨터(회사 노트북)의 Claude 메모리와 작업 기록에서 옮겼다(멀티 서비스 플랫폼 스펙 10장 1단계).

## 1. GitHub 계정과 푸시

- 저장소는 운영자 개인 계정의 `geonhee-lee0912/prologue` 다. 나중에 조직 `braveshine-labs` 로 옮길 수 있다(멀티 서비스 플랫폼 스펙 8장)
- 커밋 작성자도 푸시 계정도 개인 계정이다

**GitHub 계정이 여럿 섞인 컴퓨터** (프롤로그를 개발해 온 회사 노트북이 그렇다)

- 커밋 작성자: `~/.gitconfig` 의 `[includeIf "gitdir:~/Desktop/bs/"]` 가 `~/.gitconfig-bs`(개인 계정 이름·메일, 개인 키를 쓰는 `core.sshCommand`)를 불러온다. `user.useConfigOnly = true` 라서 이렇게 나눈 폴더 밖에서는 작성자가 없어 커밋이 거부된다
- 푸시 인증: SSH 별칭 `gh-bs` 로 클론하고 푸시한다

  ```
  # ~/.ssh/config
  Host gh-bs
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_bs
    IdentitiesOnly yes
  ```

  ```bash
  git clone gh-bs:geonhee-lee0912/<저장소>.git
  ```

  이미 HTTPS 로 받았다면 `git remote set-url origin gh-bs:geonhee-lee0912/<저장소>.git`
- 이유: `includeIf` 는 작성자만 바꾼다. 푸시 인증은 remote 주소가 정한다. HTTPS remote 는 macOS 키체인의 github.com 자격 증명을 쓰는데 그 노트북 키체인에는 회사 계정뿐이라, 작성자는 개인인데 인증은 회사 계정으로 가는 어긋남이 생긴다(2026-09-01 클론 직후 실제로 일어났다). `git remote -v` 가 `https://github.com/…` 이면 푸시 전에 고친다

**계정이 하나뿐인 컴퓨터** (개인 데스크톱)는 별칭이 필요 없다. 처음 푸시하기 전에 어느 계정으로 인증되는지만 확인한다.

## 2. 도구와 명령

- Node 20 이상(회사 노트북은 v24), pnpm 9(루트 `package.json` 의 `packageManager` 는 9.12.0). 전역 pnpm 이 없으면 `corepack pnpm …` 으로 부른다. 회사 노트북은 PATH 에 pnpm 이 없다
- `@prologue/shared` 는 빌드 결과(`dist`)를 내보낸다. shared 를 고쳤으면 api·mobile 의 타입 검사·테스트·미리보기 전에 shared 를 먼저 빌드한다
- 테스트는 전부 vitest 다. mobile 테스트는 `TZ=Asia/Seoul` 로 돈다

```bash
corepack pnpm install
corepack pnpm --filter shared build
corepack pnpm --filter shared test
corepack pnpm --filter api typecheck
corepack pnpm --filter api test
corepack pnpm --filter mobile test
```

## 3. 에이전트 실행 규칙

- `.env` 는 열거나 출력하지 않는다. 필요한 키 이름은 `.env.example` 에서 본다
- 커밋은 경로를 지정해서 한다. `git add -A`, `git add .` 는 쓰지 않는다 — 컴퓨터마다 커밋하지 않은 파일(5장)이 섞일 수 있다
- DB 에 적용하는 일(`prisma migrate deploy`, `pnpm db:rls`, `supabase db push`)은 사람이 확인한 뒤 한다. 마이그레이션 SQL 은 원격 DB 에 붙지 않고 `prisma migrate diff` 로 만든다(갈피 엔진 결정 기록 2번)
- `pnpm dev` 로 api 를 띄우면 원격 dev DB 에 붙는다. 갈피 마이그레이션을 적용하기 전에는 예약 작업이 10분마다 실패하니 돌리지 않는다(`BACKLOG.md` 10절)
- 하위 에이전트 모델: 회사 Claude Team 계정에서는 `sonnet` 하위 에이전트가 HTTP 403(`oauth_org_not_allowed`)으로 막혔다(2026-10-13). `opus`(구현·리뷰)와 `fable`(가장 무거운 리뷰)은 됐다. 403 이 다시 나면 조직 설정이 바뀐 것이니 운영자에게 알린다. 개인 계정(Claude Max)에서는 처음 쓸 때 다시 확인한다

## 4. 비밀값

- `.env` 는 각 컴퓨터에만 둔다. 저장소·문서·예시 파일에 키를 넣지 않는다(CLAUDE.md 10.4)
- 회사 노트북에는 `apps/api/.env` 가 있다. 다른 컴퓨터나 클라우드 세션은 `.env.example`(루트, `apps/api`, `apps/mobile`, `apps/admin`)을 보고 개발용 키만 넣는다(멀티 서비스 플랫폼 스펙 10장)

## 6. 로컬에서 RLS 정책 적용해 보기 (선택)

dev DB 에 적용하기 전에, 마이그레이션과 정책 파일이 `pnpm db:rls` 순서(파일 이름순)대로 끝까지 들어가는지 임시 Postgres 로 확인할 수 있다. 2026-10-14 BACKLOG 1·2번을 정리할 때 썼다.

- 준비: Postgres 16 (`brew install postgresql@16`), 저장소 루트에서 실행
- macOS 에서 걸리는 것: 로캘 때문에 "postmaster became multithreaded" 로 뜨지 않으면 `LC_ALL=C` 와 `initdb --locale=C`. 임시 폴더 경로가 길면 Unix 소켓 경로 한도(103바이트)를 넘으니 TCP 만 쓴다
- Supabase 에만 있는 것은 흉내 낸다: `auth.uid()`, `anon`·`authenticated`·`service_role` 역할, `supabase_realtime` 발행(publication)

```bash
export LC_ALL=C LANG=C
PGB=/opt/homebrew/opt/postgresql@16/bin
D=$(mktemp -d)
$PGB/initdb -D $D/pg -U postgres -A trust --locale=C --encoding=UTF8 >/dev/null
$PGB/pg_ctl -D $D/pg -o "-p 55432 -c listen_addresses=127.0.0.1 -c unix_socket_directories=''" -l $D/pg.log start
psqlx() { $PGB/psql -h 127.0.0.1 -p 55432 -U postgres "$@"; }
psqlx -qc "create database rlscheck"
psqlx -d rlscheck -q -v ON_ERROR_STOP=1 <<'SQL'
create schema auth;
create publication supabase_realtime;
create function auth.uid() returns uuid language sql stable as $$ select nullif(current_setting('request.jwt.claim.sub', true), '')::uuid $$;
create role anon; create role authenticated; create role service_role;
SQL
# 마이그레이션 다음 정책 파일. 하나라도 실패하면 멈춘다
for f in apps/api/prisma/migrations/*/migration.sql $(ls supabase/policies/*.sql | sort); do
  psqlx -d rlscheck -q -v ON_ERROR_STOP=1 -f "$f" >/dev/null || { echo "FAIL $f"; break; }
done
# RLS 가 꺼진 테이블 — 아무것도 나오지 않아야 한다
psqlx -d rlscheck -At -c "select relname from pg_class c join pg_namespace n on n.oid = c.relnamespace where n.nspname = 'public' and c.relkind = 'r' and not c.relrowsecurity and relname <> '_prisma_migrations'"
$PGB/pg_ctl -D $D/pg stop && rm -rf $D
```
