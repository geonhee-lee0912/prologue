# 스며드는 색의 범위와 농도 비교

상태 — 운영자는 스플래시에 복잡한 그래픽 메타포를 담는 방향보다 ‘스며듦’을 유지하는 편이 맞다고 했다. 짧은 첫 화면에서 이름과 편안한 첫인상을 남기도록, 특정한 윤곽 없이 넓게 풀리는 번짐의 범위·농도를 코드로 비교하는 작업을 승인했다. 세 안을 완성했으며 최종 선택은 미정이다. 기존 앱은 수정하지 않았다.

좌하단의 피치·코랄과 우상단의 연한 하늘색을 유지하고, 화면 밖에 중심을 둔 여러 그라데이션을 겹쳐 특정한 도형의 경계가 두드러지지 않게 했다. 중앙 로고 주변은 흰 여백으로 남긴다. ‘미세한 결’은 코드로 만든 가벼운 결이며 실제 색연필 자산의 완성본은 아니다. 새 이미지 생성 도구나 유료 호출은 사용하지 않았다.

## 조절과 확인

상단의 전체 범위·전체 농도는 세 안에 공통으로 적용된다. 각 안의 상대적인 차이는 유지한다. 미세한 결은 켜고 끌 수 있으며 ‘초기값’으로 원래 비교 조건에 돌아간다.

PC에서 세 화면을 나란히, 휴대폰에서 가로로 넘겨 볼 수 있다. 각 화면은 390×844, 같은 먹색 로고는 196×54로 표시했다. 로고 세 개의 로딩, 범위·농도 변경, 결 켜기/끄기, 초기화와 PC·휴대폰 배치, 화면 오류 없음을 확인했다. 실제 앱 A01은 이번 비교에서 바꾸지 않았다.

시각 검토 의견 — ②는 짧은 첫 화면에서 색이 더 넓게 느껴지면서 중앙 여백을 유지해 추천한다. ①은 더 절제돼 있고 ③은 모서리 색이 조금 더 분명하다. 운영자의 최종 선택에 맞춰 적용 범위를 의논한다.
