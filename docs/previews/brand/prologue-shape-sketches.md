# 코드로 보는 여백과 형태 스케치

상태 — 운영자는 앞선 번짐·원형의 형태가 모두 마음에 들지 않아 구도부터 다시 의논하자고 했다. 이후 이미지 생성 없이 코드로 대략적인 느낌을 함께 보여달라고 요청했다. SVG 경로로 세 구도를 그렸으며 이미지 생성 도구나 유료 호출은 사용하지 않았다. 기존 앱과 별개인 디자인 검토 자료이며 아직 채택한 구도는 없다.

이번 스케치에서는 색연필 질감을 생략했다. 같은 먹색 로고와 피치·코랄·연한 하늘색을 사용하고 큰 윤곽을 비교한다. 기본 화면의 경계는 약하게 부드럽게 처리했으며, ‘형태만’에서는 회색 면과 또렷한 윤곽으로 바뀐다. 경계 부드러움 조절은 색감 포함 상태에서만 동작한다.

## 확인 범위

각 휴대폰 프레임은 390×844, 로고는 196×54로 동일하다. PC 나란히 보기와 휴대폰 가로 이동 배치, 로고 세 개의 로딩, 두 표시 모드 전환과 선택 상태, 경계 부드러움의 양 끝 동작 및 복귀를 확인했다. 화면 오류는 없었다. 이미지 생성 도구를 사용하거나 기존 앱 A01을 수정하지 않았다.

시각 검토 의견 — ①은 큰 방향과 로고 중심의 여백을 단순하게 잡고, ②는 더 가벼운 움직임이 있으며, ③은 가장 연속적인 구조와 큰 색 비중을 가진다. 운영자의 선택에 맞춰 범위·윤곽을 조정한다. 이 스케치만으로 질감 완성도나 최종 브랜드 형태를 확정하지 않는다.
