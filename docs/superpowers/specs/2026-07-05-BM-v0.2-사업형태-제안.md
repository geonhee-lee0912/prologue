## 1. 결론 — 프롤로그는 어떤 사업인가

> **프롤로그는 앱 단독 사업이 아니라, 글 미디어(스레드/인스타 에세이 계정)가 사람을 모으고, 무료 인증 매칭 루프가 신뢰를 만들고, 그 위에서 "이야기의 형식"(이야기 라운드·프로필 공방·자기이해 리포트)을 단품으로 파는 1인 운영 미디어-커뮤니티형 소개팅 사업이다.**

내부 BM 부속 문장: **"이야기가 모으고(미디어), 이야기가 잇고(앱), 이야기의 형식을 판다(라운드·공방)."**

컨셉 문장은 **수정 없이 유지**. 근거: 국내 20~30대 1,017명 조사에서 비사용자 70%의 데이팅앱 거부 사유 1위 "진지한 만남이 어려워서"(55%), 2위 사기·허위 프로필(17%), 3위 개인정보 유출(12%) — 프롤로그 포지셔닝이 정확히 이 3개를 겨냥 (서울경제, 2025-2026 조사).

## 2. 시장 증거 (웹 리서치, 2025-2026)

### 2.1 구조적 쌍둥이의 실존 — 커피한잔
- 1인 개발자(前 카카오·네이버)가 2017년부터 8년째 운영. 사진 없는 블라인드 + 명함(회사) 인증 + 하루 소량 매칭.
- 누적 약 6만 명, 결제 전환율 18~24%(자기보고, 업계 통상 0~6% 대비), **월 순수익 1,000만원+**, 확인된 결혼 73쌍.
- 과금은 구독이 아니라 재화("커피콩"). **수익화까지 3년.** 운영 자동화로 주 4일×1시간.
- 출처: etnews.com/20251015000118, eopla.net/magazines/7110

### 2.2 "진지함 = 돈 안 됨"은 데이터와 반대 — 힌지
- 힌지 결제자당 매출 월 ~$32로 틴더($17.63)의 약 1.8배. 2024년 매출 $550M(+38% YoY), 업계 최고 성장.
- "designed to be deleted" 포지셔닝(성공=이탈)이 수익화 실패를 의미하지 않는다는 최대 반례.
- 출처: Match Group 공시(SEC 8-K), Priori Data, Business of Apps

### 2.3 느린/텍스트 데이팅의 실패 패턴 — 결제 걸 곳이 있어야 한다
- **Lex**(텍스트 개인광고형): 감성적 지지를 결제로 전환 못 해 감원·피벗.
- **Thursday**(주 1일 앱): 앱 과금 한계 → **오프라인 이벤트 티켓 판매로 사업 중심 이동**.
- **Once**(하루 1명 추천): 성장 한계 후 $18M 소규모 매각. **Coffee Meets Bagel**: 정체·하락.
- 교훈: 큐레이션·희소성 컨셉 자체는 검증됐지만, 명확한 결제 게이트(일본 Pairs 남성 구독, Pure 남성 구독) 또는 강한 브랜드 프리미엄(힌지), 또는 이벤트 티켓(Thursday)이 있어야 돈이 됐다.

### 2.4 한국 시장
- FY2025 추정: 엔라이즈(위피) 매출 342억·영업익 24억 / 큐피스트(글램) 163억·19억 / 트리플콤마(골드스푼) 110억·18억 — 시장 정체 속 수익성 개선.
- 한국 진지 계열 과금은 구독보다 **재화(하트·커피콩) 소모형이 지배적**.
- 월 1~2만원 앱과 200~400만원 결정사 사이 가격대가 구조적 공백. 큐피스트도 결정사 확장 시작(트웨니스 도쿄, 2025.11).

### 2.5 인앱결제 수수료 (재무 계획 수치)
- 2026년 상반기 현재: 구글·애플 기본 30%, **소기업 프로그램 15%** (연매출 $100만 미만 — 프롤로그 해당).
- **2026년 12월부터 구글 신체계 한국 적용 예정: 재화 15% / 구독 10%** (2026.3 발표, 미국·EU 6월 선적용).
- 제3자결제(26%)는 실익 없음. 웹 결제는 수수료 0이지만 **앱 내 유도 금지**(카카오 아웃링크 제재 전례) — 고단가 신청형 상품(라운드)만 웹 결제 우선 설계.
- 계획 수치: **블렌디드 유효 수수료 12~18%** (저단가 즉시 상품은 IAP 15%, 고단가 신청형은 웹 PG 3%대).

### 성장 축 — "많이 모으고 싶다"의 현실적 번역
- 국내 3강(MAU 10만+) 추격은 무예산 1인 조건에서 **계획 밖**. 앱 MAU보다 **미디어(스레드/인스타 에세이 계정) 팔로워가 먼저 큰다.**
- 앱의 핵심 자산이 "글"이라 콘텐츠와 제품이 같은 포맷 — 이것이 광고비 없이 유통 가능한 유일한 이유.
- 경로: 출시 3~6개월 전 미디어 선행 → 웨이팅리스트 3,000~5,000명 → 여성 우선 초대제 → 수도권 "글 읽고 쓰는 28~36" 세그먼트 한정 런칭.
- 성비 하드 룰: 여성 45% 미만이면 오픈 연기, 남성 55% 초과 시 승인 일시 중단.
- 익명 이야기 피드는 바이럴 엔진이 아니라 **미디어의 소재 공급원(연료)** — 공유 계수 K<0.1 가정. 카드 공유는 작성자 opt-in + 재식별 필터 + 공유 수 비공개.
- 최대 병목: **여성 측 유동성** — 기능이 아니라 운영 노동(24h 검수 SLA, 안전 대응)으로 풀리는 문제. 검수가 밀리면 여성이 빠지고, 여성이 빠지면 시장이 죽는다.

## 4. 정직한 숫자 (적대 검증 후 하향 조정)

| | 12개월 | 24개월 |
|---|---|---|
| MAU (보수) | 300~1,000 | 정리 또는 2,000 미만 정체 (**확률 40~50% — 계획 기본값**) |
| MAU (기본) | 1,500~5,000 | 8,000~25,000 |
| MAU (낙관, 확률 10~15%) | 8,000~20,000 | 40,000~80,000 |
| 창업자 월 순수익 | **~100만 미만 (무급 구간)** | 1만 MAU + 라운드 정착 시 **세전 450~600만** |

- 3만 MAU 도달 시 월 2,000~3,000만 (검수·CS 외주 차감) — 단 24개월 내 도달 확률 10% 미만, 3년차 이후 시나리오.
- 재무 검증에서 잡힌 것: 원안(650~850만)은 **부가세(매출의 1/11) 누락 + 블렌디드 수수료 낙관(8~12%→현실 12~18%) + 라운드 성비 할인 미반영**으로 25~35% 과대 계상 → 세전 450~600만으로 수정.
- **런웨이 요건: 24개월 생활비+운영비 약 7,000만~1억.** 인증 원가(가입자당 ~300원)는 매출에 선행 지출. "생활비 별도 확보 필수" 한 줄로는 부족 — 조달원·월 번레이트 명세 필요 (열린 결정).
- 유료 전환 계획치: 결제자 4~6%, ARPU 300~500원 기본 (틴더식 19~21%는 이 설계에서 영원히 안 나옴). 커피한잔의 18~24%는 상방 참고치일 뿐.

## 5. 원칙 변경 목록 (기존 문서 대비)

1. 원칙 ①(무료 핵심 루프)·②(반응 확인 무료)·⑤(상품화·결핍자극 금지)·⑥(억지 추천·무료 배제 금지): **전부 유지.** ②는 하루 1~3장 구조상 팔 재고 자체가 없어 지키는 비용 ~0, 브랜드 서사 가치만 큼.
2. 부스트/상위노출·매칭 보장 금지: **절대 유지** — 유일하게 "살아남는 변형이 없는" 지렛대. 노출 판매 = 큐레이터 메모의 광고화 = 컨셉 붕괴.
3. **Trust Plus·고신뢰 풀 공식 폐기** (BM 전략 v0.1 Phase 3 격하). 원칙 ③ 문구 정밀화: "풀 접근권 금지"는 유지하되 심화 인증 실비 배지(단일 풀, 표시 전용, 추천 점수 무영향)는 예외 허용. **단, 연봉·자산·학벌 인증은 영구 금지 명문화** (결정사행 경사로 봉쇄). 배지는 무료 인증 배지와 동일 시각 위계, 수익 상품이 아니라 원가 공개형 옵션으로 분류.
4. 추천권 월 한도: "한도의 존재"는 원칙 유지, 고정 수치는 **하향 단방향 다이얼**(부족 시 축소·중단만, 상한 월 5장 고정)로 전환. 내부 용어 "재고" → "추천 가능 후보 품질"로 교체.
5. **무료 추천 수: "하루 1장"으로 확정 제안** (문서 A "주 1~2명" vs IA v0.2 "하루 3장" 충돌 해소). 단, 결정 근거는 매칭 품질·습관 형성 — "추천권 수요(수익)"를 근거에 넣지 않는다 (검증 반영).
6. **신규 원칙 ⑦: 익명 이야기 피드는 영구 무과금 성역** — 발행 슬롯·노출 부스트·조기 신원 공개 판매 전면 금지. 사용자 이야기 조각의 미디어 계정 사용은 opt-in 없이는 금지.
7. **신규 원칙 ⑧: 쿨다운 오퍼** — 유료 제안은 감정 이벤트 당일이 아니라 이후 차분한 시점에만. 카운트다운 UI·대화 만료 임박 화면·빈 상태 화면에 결제 진입점 금지. ("설렐 때 지갑을 열게 하지 않는다"를 브랜드 자산으로.)
8. 라운드 예외 조항은 **좁게** 작성: "기간 한정 이벤트형 + 참가자가 일반 무료 풀에 완전 잔류 + 상시 풀/속성 필터형 접근권은 영구 금지" (직업별·고소득 라운드 같은 뒷문 봉쇄). 개시 전 미성립(성비·인원 미달)은 **전액 환불 기본**(전자상거래법 청약철회 정합), 결제 전 "만남 성립을 보장하지 않습니다" 명시.

## 6. 적대 검증 요약

두 감사 모두 **사업 골격은 기각하지 않음** (refuted=false). 무너지지 않은 것: 미디어 선행 성장, 무료 신뢰 루프, 구독 배제 논리, 피드 무과금 성역, 라운드의 임계 MAU 전 출시 금지.

**재무·운영 감사가 잡은 것 (수정 반영):**
- 부가세·종합소득세 누락 → 순익 하향 (§4)
- 수수료 자기모순 → 상품×채널 매트릭스 (저단가=IAP 15%, 고단가 신청형=웹 PG)
- 라운드 3중 낙관 (참가율·성비 정가·한계비용 0) → 민감도 테이블 필요 (열린 결정)
- 크레딧-대신-환불의 소비자법 충돌 → 전액 환불 기본으로 수정
- 획득 엔진 무근거 → Phase 0 게이트를 결과 지표로 (팔로워 N, 주간 유입 M, 유입→가입 전환 X% 미달 시 출시 연기)
- 외주 트리거를 MAU가 아닌 처리량 기준으로 (월 신규 800~1,000건 또는 주당 운영 15시간 초과 시)
- 라운드 임계 "7천 MAU"를 직접 지표로 교체: "2주 내 성비 균형 선결제 40명 확보 가능" 여부로 판정

**브랜드·신뢰 감사가 잡은 것 (수정 반영):**
- 공방의 AI 글 생성 = "글=사람" 신호를 플랫폼이 오염 → 생성 금지, 질문·피드백만. 배치도 온보딩 직전(불안 자극)이 아니라 가입 후 자발 진입으로
- "감정 피크의 단품" 독트린 = 구조적 다크패턴 → 쿨다운 오퍼 원칙(⑧)으로 대체
- 라운드 예외 조항 = 프리미엄 풀 뒷문 → 문구 축소 (§5-8)
- 추천권 "풍부 시 확대" = 여성 노출이 남성 구매에 연동되는 부스트의 쌍대 → 하향 단방향으로
- "다시 잇기" = 여성의 소프트 페이드(안전한 이탈)를 유료로 재개방 → 로드맵에서 제거
- 매칭 리포트의 상대 분석 = 타인 데이터의 동의 없는 유료 원료화 → 구매자 자신 서술로 한정

## 8. 창업자가 감수해야 하는 것

1. **첫 12~18개월은 사실상 무급** (월 순수익 100만 미만). 생활 자금은 사업 밖에서. 인증 원가는 매출에 선행.
2. **기본값은 실패** — 24개월 내 2,000 MAU 미만 정체 확률 40~50%. 부정하지 말고 중단 기준과 함께 계획에 넣는다.
3. "많이 모으고 싶다"는 재정의된다 — 국내 3강 추격은 계획 밖. 현실적 성공은 24개월 8천~2.5만 MAU + 앱보다 먼저 크는 미디어.
4. 매일의 콘텐츠 노동(30~60분)과 24시간 검수·신고 SLA가 개발 시간과 영구히 경쟁. 잠자는 8시간이 SLA 공백.
5. 가장 큰 수익 기둥(라운드)은 1년차에 못 판다. 첫 해 매출은 월 수십만~200만이 정직한 숫자.
6. 커피한잔도 수익화까지 3년. 유사한 시간축을 각오.
7. 성공=졸업 구조라 획득이 멈추면 MAU가 2~3개월 내 반토막. 획득 루프 노동은 끝나지 않는다.
8. 원칙을 지키는 대가로 결제자 4~6%·ARPU 300~500원 구조가 기본 — 틴더식 전환율은 영원히 안 나온다.
