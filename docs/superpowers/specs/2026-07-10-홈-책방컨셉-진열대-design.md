## 1. 배경과 목적

추천 탭(홈)의 기존 화면은 "오늘의 프롤로그" 제목 + 사진 앞세운 카드 리스트로, 브랜드 메타포(책방/서점·사서)가 거의 드러나지 않았다. 또한 v0.3에서 확정된 **하루 2장 택1**·**표지=텍스트 제목**·**추가 소개 세트(확장)** 가 반영돼 있지 않았다.

이 문서는 홈을 **"사서가 진열대에 오늘의 책을 골라 두는 책방"** 으로 재설계한다. 핵심 목표 셋:

1. 책방·사서 메타포를 홈의 구조와 목소리에 자연스럽게 반영.
2. v0.3의 2장 택1과 정합.
3. **추가 소개 세트를 사면 진열대가 계속 늘어나는** 확장성을 구조적으로 감당.

## 2. 컨셉 원칙

| ID | 원칙 |
|---|---|
| HOME-1 | **사서는 목소리로만 존재한다.** 아바타·이름 있는 캐릭터·말풍선 인격체로 등장하지 않는다. 상단 인사, 진열대 안내판, 책마다 띠지 메모가 일관된 사서(책방지기/프롤로그 큐레이터) 말투로 흐른다. |
| HOME-2 | **책방 공간감은 은은하게.** 서가·진열대의 감각은 질감·여백·세리프 타이포·"틀"로만. 과한 스큐어모피즘(나무 책장 그래픽 등) 금지. |
| HOME-3 | **둘러보기(서가)는 2번 탭(이야기), 지난 인연 추적은 3번 탭(이어짐)** 이 맡는다. 홈은 "오늘 사서가 고른 것"에 집중하고 다른 탭 기능을 복제하지 않는다. |

## 3. 홈 구조 (HOME-STRUCT)

전체 **세로 스크롤 한 축**. 위에서 아래로:

```
[상단 인사]            사서의 하루 인사 (하루 리듬)
[오늘의 진열]          기본 진열대 (무료) — 2권 택1
[청하신 한 묶음] …     추가 세트 (재화 구매) — 2권 택1, 여러 개 반복 가능
[한 묶음 더 청하기]    추가 세트 구매 진입
[지난 진열]            해소된/지난 진열대 아카이브 (책등만, 이어짐으로 위임)
[사서 코너]            추천 설명 + 취향·인증 다듬기 진입
```

| ID | 결정 |
|---|---|
| STRUCT-1 | 스크롤은 **세로 한 축**. 진열대 안 2권도 세로, 진열대끼리도 세로. 가로 스와이프 없음(발견성·접기·단순성 위해). |
| STRUCT-2 | **진열대는 반복 컴포넌트.** 기본 진열대와 추가 세트는 동일한 UI. 세트가 늘면 아래로 반복될 뿐 구조가 바뀌지 않는다. |
| STRUCT-3 | 표지 모양은 **세로 통일.** 무료/유료로 모양을 다르게 하지 않는다(존엄·일관성). 위계 구분은 모양이 아니라 **상태(활성/해소)** 로 준다. |

## 4. 진열대 = 택1 "틀" (SHELF)

세로로 쌓이면 "이 둘이 한 세트(택1)"라는 그룹핑이 흐려진다. 이를 **뚜렷한 틀**로 해결한다.

| ID | 결정 |
|---|---|
| SHELF-1 | 각 진열대는 **경계가 분명한 패널**(둥근 테두리·여백)로 두 권을 감싼다. "이 틀 안 두 권 = 한 번의 선택". |
| SHELF-2 | 패널 상단 **안내판**: 사서 아이콘 + 진열대 이름("오늘의 진열" / "청하신 한 묶음") + 우측에 규칙 문구("이 중 한 분께"). |
| SHELF-3 | 두 권 사이 **"또는" 칩**(구분선 위 칩)으로 "둘 중 선택"을 시각화. |
| SHELF-4 | 진열대끼리는 **큰 간격 + 다른 안내판 이름**으로 세트 경계를 분명히 한다. |

## 5. 책 표지 (COVER)

v0.3 BOOK-표지(표지=텍스트 제목, 얼굴 없음) 위에 이번 세션 결정을 더한다.

| ID | 결정 |
|---|---|
| COVER-1 | 표지 헤드라인 = **사용자가 쓴 한 줄 책 제목**(세리프). 최소 메타 = 나이·지역 + 인증 배지. 스펙 6종(소득·자산·학벌·학교·회사·키)은 표지에 없고 **펼친 내지**에 정밀값으로. |
| COVER-2 | **대표 사진을 진하게 블러 처리해 표지 배경에 깐다.** 얼굴 형태는 뭉개지고 색·분위기만 남는 강도. 그 위에 어두운 스크림 + 밝은 텍스트. | 
| COVER-3 | **블러 강도는 "평가 대상이 아닌 분위기" 수준으로 고정**(CONCEPT-2 얼굴 대결 차단·개인정보 보호). 선명 얼굴 노출 금지. 사진 미등록자는 색 표지(블러 없음)로 폴백. |
| COVER-4 | 책마다 하단 **띠지(오비)** = 큐레이터의 메모(왜 이 책을 골랐는지, 설명형 한 줄). 점수·보장 표현 금지. |

## 6. 상호작용 — 택1 (PICK)

| ID | 결정 |
|---|---|
| PICK-1 | 진열대의 두 권 모두 **펼쳐 읽기 가능**. 관심은 **한 분께**(택1). 선택 = 관심 투자처. |
| PICK-2 | **선택된 책** → 관심 발신. 진열대는 "택1 완료"로 접힘(§7). 상태 문구: "이 분께 첫 장을 건넸어요 · 답을 기다려요". 이후 추적은 이어짐 탭. |
| PICK-3 | **안 선택된 책** → 명시적 "거절" 버튼 없음. 택1하면 조용히 물러난다. **거절 아님·기록 없음·재등장 가능.** 안심 문구: "고르지 않은 다른 한 분은 다시 만날 수도 있어요". |
| PICK-4 | **아무것도 안 고르면** → 기한 경과 시 둘 다 무신호로 "지난 진열"로 접히고 재등장 후보로 복귀. |
| PICK-5 | **유료로 둘 다 열기(보조 선택지).** 재화 지불 시 그 세트의 두 분 모두에게 관심 가능. **택1이 기본·주동작**이고 이건 조용한 보조로 배치. 프레이밍은 "두 분 다 만나보기"(제한 해제·요금소 톤 금지). ⚠ 컨셉 문장(순수 택1)과 긴장 → 거버넌스 플래그(§10). |

## 7. 상태 흐름 — 접힘 (COLLAPSE)

홈은 세트가 해소될수록 위로 가벼워진다. 세 위계:

| 상태 | 표현 |
|---|---|
| **활성 진열대** | 펼쳐진 큰 세로 표지 2권 (틀·안내판·또는·액션) |
| **방금 고른 진열대** | 접힌 슬림 바 — 고른 책 미니 표지 + "첫 장을 건넸어요 · 답을 기다려요" + 안심 문구. 탭 시 이어짐/상세. 안 고른 책 미표시. |
| **지난 진열(아카이브)** | 책등만 남은 행 — "관심 보낸 N분", "이어짐에서 보기" 딥링크. 실제 추적은 이어짐에 위임(중복 방지). |

| ID | 결정 |
|---|---|
| COLLAPSE-1 | 활성인 진열대만 크게. 해소·지난 것은 접어 홈 길이를 억제 → **무한 추가 세트에도 홈이 터지지 않는다.** |
| COLLAPSE-2 | 접힘 표현은 항상 **고른 책만** 드러낸다. 안 고른 책은 어디에도 남기지 않는다(존엄). |

---

## 8. 확장 — 한 묶음 더 청하기 (EXPAND)

| ID | 결정 |
|---|---|
| EXPAND-1 | "한 묶음 더 청하기"(재화) → 새 진열대(다른 2권) 추가. 일 제한 없음(v0.3 REC-세트). |
| EXPAND-2 | 프레이밍 = **"사서에게 두 분을 더 부탁"** 하는 의식. 결핍 자극("놓치면 후회"·"지금 안 보면 끝") 금지. |
| EXPAND-3 | 진입점 위치 = 활성 진열대들 **아래 한 곳**(1차). 각 진열대 사이 삽입은 하지 않는다(1차). |

## 9. 사서 코너 (CORNER) · 빈 상태 (EMPTY)

| ID | 결정 |
|---|---|
| CORNER-1 | 홈 하단 **사서 코너** = ①"왜 이런 책이 왔을까요"(오늘의 큐레이션 기준, 점수 없이 설명형) ②"취향 다듬기 · 인증 더하기"(선호 설정·인증 진입). 추천을 설명하고 더 나은 추천으로 잇는 구획. |
| EMPTY-1 | 오늘 고른 책이 없으면 **빈 상태**: 사서의 차분한 안내("오늘은 골라 둘 만한 분을 찾지 못했어요. 프로필을 더 채우면 좋은 분이 도착할 가능성이 높아져요"). 억지 추천 금지(v0.3). 취향·인증 진입 제공. |

## 11. 카피 (사서 톤) · 금지 표현 체크

권장 톤: 차분·따뜻·설명적. 아래 카피는 후보이며 최종 확정 전 톤 가이드 재검토.

- 상단 인사: "책방지기가 오늘 두 분을 골라 두었어요. 천천히 읽어보세요."
- 안내판 규칙: "이 중 한 분께"
- 띠지 메모(예): "느린 대화를 좋아하신다는 점이 닮았어요"
- 택1 완료: "이 분께 첫 장을 건넸어요 · 답을 기다려요"
- 안심 문구: "고르지 않은 다른 한 분은 다시 만날 수도 있어요"
- 한 묶음 더: "사서에게 두 분을 더 부탁해요"

금지 표현 체크(CLAUDE.md §9): 운명·완벽·보장·100%·"놓치면 후회"·상품화(쓸어보기/장바구니 등)·답장 압박 — 위 카피에 없음. ✅
