# 앱 IA v2 화면 골격 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `apps/mobile`에 앱 IA v2(친구 / 대화 / 내 이야기 / 설정)의 화면 골격과 갈피 대화방·편지·가벼운 소개·친구 탭·대화 탭을 mock 데이터로 세워, 브라우저 미리보기에서 핵심 흐름을 끝까지 눌러 볼 수 있게 한다.

**Architecture:** 규칙(편지 만료, 한 번에 한 통, 친구 탭 우선순위, 소식, 대화 목록, 갈피 대본)은 React Native를 모르는 순수 TypeScript 모듈 `apps/mobile/domain/`에 두고 Vitest로 검증한다. 화면은 expo-router 파일 라우팅으로 만들고, 상태는 zustand 저장소 하나가 `domain/actions.ts`의 순수 함수를 감싼다. 백엔드·네트워크 호출은 없다 — 모든 데이터는 `mock/scenarios.ts`에서 온다.

**Tech Stack:** Expo SDK 54, expo-router 6, React 19.1.0, React Native 0.81, zustand 4, expo-image, @expo/vector-icons, @expo-google-fonts/gowun-batang, Vitest 2, pnpm 9(corepack), Next.js 15(admin, React 통일 때문에)

**Spec:** `docs/superpowers/specs/2026-10-10-서비스-구성-위계-design.md` (앱 IA v2.1). 함께 읽을 것: `docs/superpowers/specs/2026-10-09-브랜드-세계관-갈피-design.md` 3.6(갈피의 말·행동), `CLAUDE.md` 1.1 하드룰·9장 카피 규칙

## Global Constraints

- **명령은 `corepack pnpm`으로.** 이 기기에는 `pnpm`이 PATH에 없다. 예: `corepack pnpm --filter mobile test`
- **React는 워크스페이스 전체가 정확히 `19.1.0`.** React Native 0.81 렌더러가 정확한 버전 일치를 요구하고, expo-router 6은 React 19의 `use`를 쓴다(Task 1)
- **`apps/mobile/domain/`과 `apps/mobile/mock/`은 `react`, `react-native`, `expo-*`를 import하지 않는다.** Vitest(node)에서 돌아야 한다
- **정책 숫자는 `@prologue/shared/policy`의 `POLICY`에서만** 읽는다. magic number 금지(CLAUDE.md 12장)
- **테스트는 `TZ=Asia/Seoul`로 돈다** (`apps/mobile/package.json`의 test 스크립트). 날짜 계산은 기기 시간대 기준
- **하드룰 1 진열 금지**: 친구 탭에는 사람이 들어오지 않는다. 소식에는 다른 사용자의 이름·사진·이야기가 익명으로도 나오지 않는다. 편지함·지난 소개 모음을 만들지 않는다
- **하드룰 2**: 넘긴 이유는 어떤 화면에도 다시 보여주지 않는다. 넘긴 이유를 묻는 곳에는 "이 말은 상대에게 전달되지 않아요"를 적는다
- **하드룰 3**: "매일 N명" 같은 개수 약속, 남은 개수 숫자 표시 금지. 가벼운 소개가 없을 때는 "오늘은 여기까지예요"
- **하드룰 5**: 연락처 교환은 대화방 메뉴 안쪽에만, 권하는 문구 없음
- **하드룰 6**: 사람 대화에 읽음 표시·온라인 상태 없음. 갈피 대화의 새 말은 숫자 없이 점 하나. 갈피와의 관계 장치(태엽)는 보상만, 벌·게이지·숫자 없음
- **카피 금지 표현**(CLAUDE.md 9.1): 운명, 완벽, 보장, 100%, "놓치면 후회", "곧 사라져요", "빨리 답장", "상대가 기다리고 있어요", "왜 안 와요" 등
- **세계관은 갈피의 말에만.** 버튼은 뜻이 바로 보이게 담백하게(갈피 문서 2.7). 갈피의 말과 편지만 명조(`GowunBatang_400Regular`), 나머지는 시스템 글꼴
- **AI 고지**: 갈피 대화방 맨 위에 "갈피는 AI예요"를 적는다(CLAUDE.md 13장)
- **디자인 기준(잠정, IA 10.6)**: 바탕 `#FBFAF7` 모노톤 + 파스텔 포인트. 기본 팔레트는 라벤더·버터, 개발용 스위처로 하늘·살구 / 로즈·올리브와 비교
- **화면 ID 추적**: 새 구조에서는 한 화면이 여러 기존 화면 ID를 품으므로(IA 3.5 표), 파일명 prefix 대신 **파일 맨 위 주석 `@screen`에 기존 ID를 적는다** (CLAUDE.md 8.1의 목적인 추적성을 유지. Task 14에서 CLAUDE.md에 반영)
- **화면 검증**: 화면은 단위 테스트 대신 Expo 웹 미리보기로 확인한다. `.claude/launch.json`의 `mobile-web`(포트 8081)과 `device-frame`(포트 8090, 휴대폰 프레임). 콘솔 오류가 없고 아래 각 Task에 적힌 글자가 보이면 통과. 상태는 메모리에만 있어서 **주소창으로 이동(새로고침)하면 "첫 실행" 시나리오로 돌아간다** — 시나리오를 바꾼 뒤에는 탭과 버튼으로만 이동한다. `apps/mobile`에는 eslint 설정이 없어 lint는 이 계획의 범위 밖
- **커밋 메시지**: CLAUDE.md 8.3 형식 + 마지막 줄 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. 작업은 main이 아닌 작업 브랜치(예: `feat/mobile-ia-v2`)에서

## Review Focus

1. **편지 만료 그 순간** — 보낸 지 정확히 7일이 되는 순간 편지는 닫혀야 하고, 1ms 전에는 열려 있어야 한다 → Task 3 `기한 1ms 전에는 열려 있고, 기한 그 순간부터 만료다`
2. **일주일 뒤 같은 요일에 끝나는 편지** — "토요일까지"라고만 쓰면 오늘(토)과 헷갈린다. 날짜와 요일을 함께 쓴다 → Task 2 `일주일 뒤 같은 요일도 날짜로 구분된다`, Task 3 `기한 표기는 날짜와 요일`
3. **두 후보 중 고르지 않은 쪽** — 수락·연결·넘김·만료 어느 뒤에도 고르지 않은 사람의 이름·사진이 열리면 안 된다 → Task 3 `고르지 않은 후보는 열리지 않는다` 묶음
4. **소식에 다른 사용자가 섞이는 것** — 가벼운 소개·연결·편지가 있어도 소식에는 그 사람들의 이름·사진·이야기가 나오면 안 된다 → Task 4 `다른 사용자의 이름·사진·이야기는 소식에 절대 나오지 않는다`
5. **끝난 연결과 넘긴 편지의 사진** — 대화 목록의 지난 대화와 넘긴 편지에서 사진이 남으면 안 된다 → Task 5 `끝난 연결은 지난 대화로, 사진 없이`, Task 3 `넘기거나 만료되면 사진까지 닫힌다`

/**
 * 날짜 계산 — 기기 시간대 기준.
 * 테스트는 TZ=Asia/Seoul 로 돈다 (package.json test 스크립트).
 */
const DAY_MS = 24 * 60 * 60 * 1000;
const WEEKDAYS = ['일', '월', '화', '수', '목', '금', '토'] as const;

export function addDays(date: Date, days: number): Date {
  return new Date(date.getTime() + days * DAY_MS);
}

/** 달력 날짜 차이 (a - b). 시각은 무시한다. 23:50 과 다음 날 00:10 은 1 */
export function calendarDayDiff(a: Date, b: Date): number {
  const ua = Date.UTC(a.getFullYear(), a.getMonth(), a.getDate());
  const ub = Date.UTC(b.getFullYear(), b.getMonth(), b.getDate());
  return Math.round((ua - ub) / DAY_MS);
}

/** "10월 17일 토요일까지". 요일만 쓰면 일주일 뒤 같은 요일이 오늘과 헷갈린다 */
export function untilLabel(date: Date): string {
  return `${date.getMonth() + 1}월 ${date.getDate()}일 ${WEEKDAYS[date.getDay()]}요일까지`;
}

/** 그날이 끝나는 순간 (다음 날 0시) */
export function endOfLocalDay(date: Date): Date {
  return new Date(date.getFullYear(), date.getMonth(), date.getDate() + 1);
}

/** "2026-10-10" — 하루 단위 키 */
export function localDateKey(date: Date): string {
  const m = String(date.getMonth() + 1).padStart(2, '0');
  const d = String(date.getDate()).padStart(2, '0');
  return `${date.getFullYear()}-${m}-${d}`;
}

/** 방의 밤 — 19시부터 다음 날 6시 전까지. 화면의 틀은 그대로, 방 안만 바뀐다 (IA 3.6) */
export function isNight(date: Date): boolean {
  const h = date.getHours();
  return h >= 19 || h < 6;
}

/** 하루 동안 같은 항목을 고른다 — 갈피의 하루 한마디, 일지 */
export function pickByDay<T>(items: readonly T[], date: Date): T {
  const day = Math.floor(Date.UTC(date.getFullYear(), date.getMonth(), date.getDate()) / DAY_MS);
  return items[day % items.length];
}

/**
 * 편지 규칙 — 앱 IA 4.1(두 종류의 소개 중 메인), 5장(편지는 관계를 따라간다)
 *
 * - 후보가 둘이면 이야기 한 줄로 하나를 고른다. 고른 쪽만 열린다
 * - 한 번에 한 통. 지금 편지에 답하기 전엔 다음 편지가 오지 않는다
 * - 7일 뒤 만료. 넘기거나 만료되면 사진까지 닫힌다
 */
import { POLICY } from '@prologue/shared/policy';
import { addDays, untilLabel } from './time';
import type { Letter, LetterProfile, LetterStatus, StoryCandidate } from './types';

const AWAITING: readonly LetterStatus[] = ['choosing', 'open'];

export function createLetter(args: {
  id: string;
  candidates: StoryCandidate[];
  profiles: Record<string, LetterProfile>;
  sentAt: Date;
}): Letter {
  const { id, candidates, profiles, sentAt } = args;
  const max = POLICY.introduction.maxStoryChoices;
  if (candidates.length < 1 || candidates.length > max) {
    throw new Error(`편지 후보는 1~${max}명이어야 한다`);
  }
  const single = candidates.length === 1;
  return {
    id,
    candidates,
    profiles,
    chosenCandidateId: single ? candidates[0].id : null,
    status: single ? 'open' : 'choosing',
    sentAt: sentAt.toISOString(),
    expiresAt: addDays(sentAt, POLICY.introduction.letterExpiryDays).toISOString(),
  };
}

export function isExpired(letter: Letter, now: Date): boolean {
  return now.getTime() >= new Date(letter.expiresAt).getTime();
}

/** 내 답을 기다리는 편지인가 (고르는 중이거나 열렸고, 아직 기한 안) */
export function isAwaitingMyAnswer(letter: Letter, now: Date): boolean {
  return AWAITING.includes(letter.status) && !isExpired(letter, now);
}

/** "10월 17일 토요일까지 열려 있어요" — 사실만 말하고 재촉하지 않는다 (CLAUDE.md 9.1) */
export function expiryLabel(letter: Letter): string {
  return `${untilLabel(new Date(letter.expiresAt))} 열려 있어요`;
}

export function chooseCandidate(letter: Letter, candidateId: string): Letter {
  if (letter.status !== 'choosing') return letter;
  if (!letter.candidates.some((c) => c.id === candidateId)) {
    throw new Error('편지에 없는 후보다');
  }
  return { ...letter, chosenCandidateId: candidateId, status: 'open' };
}

/** 고른 후보의 편지만 열린다. 고르지 않은 쪽은 어떤 상태에서도 열리지 않는다 */
export function revealedProfile(letter: Letter): LetterProfile | null {
  if (letter.status === 'choosing' || letter.status === 'passed' || letter.status === 'expired') {
    return null;
  }
  if (!letter.chosenCandidateId) return null;
  return letter.profiles[letter.chosenCandidateId] ?? null;
}

export function acceptLetter(letter: Letter): Letter {
  if (letter.status !== 'open') return letter;
  return { ...letter, status: 'acceptedWaiting' };
}

export function passLetter(letter: Letter, reason?: string): Letter {
  if (!AWAITING.includes(letter.status)) return letter;
  const trimmed = reason?.trim();
  return { ...letter, status: 'passed', ...(trimmed ? { passReason: trimmed } : {}) };
}

/** 답 없이 기한이 지난 편지와, 상대 답을 기다리다 기한이 지난 편지를 닫는다 */
export function applyExpiry(letters: Letter[], now: Date): Letter[] {
  return letters.map((l) =>
    (AWAITING.includes(l.status) || l.status === 'acceptedWaiting') && isExpired(l, now)
      ? { ...l, status: 'expired' as const }
      : l,
  );
}

/** 한 번에 한 통 — 답하지 않은 편지가 있거나 쉬는 중이면 다음 편지를 받지 않는다 */
export function canReceiveNextLetter(letters: Letter[], now: Date, paused: boolean): boolean {
  if (paused) return false;
  return !letters.some((l) => isAwaitingMyAnswer(l, now));
}

        href: '/galpi/chat',
      },
      meetingConnectionId: pendingMeeting.connectionId,
    });
  }

      kind: 'letterArrived',
      galpiLine: `${name} 님, 편지를 썼어요 ✉️`,

      },
    });

  if (!state.interview.completed) {
    const started = state.interview.step > 0;
    events.push({
      kind: 'interviewResume',
      galpiLine: started ? '지난번엔 여기까지 이야기했어요.' : '천천히 시작해도 괜찮아요. 요즘 어떻게 지내요?',

        title: started ? '이야기를 이어서 할까요?' : '갈피와 이야기를 시작해 볼까요?',
        subtitle: started ? '지난번엔 여기까지 이야기했어요' : undefined,
        actionLabel: started ? '이어서 하기' : '시작하기',
        href: '/galpi/chat',
      },
    });
  }

  // 5. 편지 고민 중 — 카드 없이 말로만
  if (state.considering) {
    events.push({
      kind: 'letterConsidering',
      galpiLine: `편지를 쓸지 고민 중인 분이 있어요. ${state.considering.hint}`,
      card: null,
    });
  }

  // 6. 오랜만에 옴 — 반가워할 뿐, 탓하지 않는다
  if (
    state.previousVisitAt &&
    calendarDayDiff(now, new Date(state.previousVisitAt)) >= POLICY.galpi.welcomeBackAfterDays
  ) {
    events.push({ kind: 'welcomeBack', galpiLine: `${name} 님! 반가워요 ☕`, card: null });
  }

  // 7. 평소
  events.push({ kind: 'everyday', galpiLine: everydayLine(now), card: null });
  return events;
}

/**
 * 대화 탭 목록 — 앱 IA 6장
 *
 * - 갈피는 맨 위 고정. 새 말은 숫자 없이 점 하나 (하드룰 6, 갈피는 먼저 말을 거는 일이 잦다)
 * - 사람은 서로 수락한 분만. 안 읽은 수는 나에게만 보인다. 상대 쪽 읽음 표시는 없다
 * - 끝난 연결은 "지난 대화"로, 사진 없이 이름만 (하드룰 1)
 */
import type { AppState, GalpiMessage } from './types';

export interface GalpiRow {
  preview: string;
  hasNew: boolean;
}

export interface PersonRow {
  id: string;
  name: string;
  photoUri: string | null;
  preview: string;
  unreadCount: number;
  lastAt: string | null;
}

export interface PastRow {
  id: string;
  name: string;
}

export interface ChatList {
  galpi: GalpiRow;
  active: PersonRow[];
  past: PastRow[];
}

export function galpiPreview(message: GalpiMessage | undefined): string {
  if (!message) return '갈피와 이야기를 시작해 보세요';
  switch (message.kind) {
    case 'text':
      return message.text;
    case 'emoticon':
      return '(이모티콘)';
    case 'letter':
      return '✉️ 편지를 썼어요';
    case 'lightIntroInvite':
      return '가볍게 볼 분이 있어요';
    case 'passedLetter':
      return '넘긴 편지';
  }
}

export function buildChatList(state: AppState): ChatList {
  const last = state.galpiMessages[state.galpiMessages.length - 1];
  const readAt = state.galpiLastReadAt;
  const hasNew = state.galpiMessages.some((m) => m.from === 'galpi' && (readAt === null || m.at > readAt));

  const active: PersonRow[] = state.connections
    .filter((c) => !c.ended)
    .map((c) => {
      const lastMessage = c.messages[c.messages.length - 1];
      return {
        id: c.id,
        name: c.name,
        photoUri: c.photoUri,
        preview: lastMessage ? lastMessage.text : '서로 이야기 나눠 보기로 했어요',
        unreadCount: c.messages.filter((m) => m.from === 'them' && (c.lastReadAt === null || m.at > c.lastReadAt)).length,
        lastAt: lastMessage ? lastMessage.at : null,
      };
    })
    .sort((a, b) => (b.lastAt ?? '').localeCompare(a.lastAt ?? ''));

  const past: PastRow[] = state.connections.filter((c) => c.ended).map((c) => ({ id: c.id, name: c.name }));

  return { galpi: { preview: galpiPreview(last), hasNew }, active, past };
}

export function replyToUser(state: AppState, opts: { skipped: boolean }, ctx: ScriptContext): ScriptResult {
  const at = ctx.now.toISOString();
  const text = (t: string): GalpiMessage => ({ id: ctx.newId(), kind: 'text', from: 'galpi', text: t, at });

  if (state.interview.completed) {
    const reply = EVERYDAY_REPLIES[state.galpiMessages.length % EVERYDAY_REPLIES.length];
    return { replies: [text(reply)], interview: state.interview, newChapters: [] };
  }

  const answered = state.interview.step + 1;
  const total = Math.min(INTERVIEW_QUESTIONS.length, POLICY.interview.minTurns);
  const replies: GalpiMessage[] = [
    text(opts.skipped ? '괜찮아요. 다른 이야기로 가 볼게요.' : ACKS[state.interview.step % ACKS.length]),
  ];

  const newChapters: Chapter[] = [];
  const chapterTitle = CHAPTER_AT[answered];
  if (chapterTitle) newChapters.push({ id: ctx.newId(), title: chapterTitle, addedAt: at });

  const completed = answered >= total;
  if (completed) {
    replies.push({ id: ctx.newId(), kind: 'emoticon', from: 'galpi', expression: 'proud', at });
    replies.push(text('이야기 들려줘서 고마워요. 제가 읽은 당신을 편지로 써서 내 이야기 탭에 두었어요 ✉️'));
  } else {
    replies.push(text(INTERVIEW_QUESTIONS[answered]));
  }

  return { replies, interview: { step: answered, completed }, newChapters };
}

 * 바뀌는 게 없으면 받은 state 를 그대로 돌려준다 (저장소가 불필요하게 다시 그리지 않도록).

import { firstMeetingMessages, replyToUser } from './galpi-script';
import { acceptLetter, applyExpiry, chooseCandidate, passLetter } from './letters';
import type { AppState, Connection, GalpiMessage, Keepsake } from './types';

export interface Ctx {
  now: Date;
  newId: () => string;
}

const galpiText = (ctx: Ctx, text: string): GalpiMessage => ({
  id: ctx.newId(),
  kind: 'text',
  from: 'galpi',
  text,
  at: ctx.now.toISOString(),

/** 기념품은 종류마다 한 번만 — 여정의 순간에만 생긴다 (IA 3.7) */
function withKeepsake(state: AppState, kind: Keepsake['kind'], ctx: Ctx): Keepsake[] {
  if (state.keepsakes.some((k) => k.kind === kind)) return state.keepsakes;
  return [...state.keepsakes, { id: ctx.newId(), kind, at: ctx.now.toISOString() }];
}

export function beginSession(state: AppState, ctx: Ctx): AppState {
  return {
    ...state,
    previousVisitAt: state.lastVisitAt,
    lastVisitAt: ctx.now.toISOString(),
    letters: applyExpiry(state.letters, ctx.now),
  };
}

export function startFirstRun(state: AppState, ctx: Ctx): AppState {
  if (state.firstRunDone) return state;
  return {
    ...state,
    firstRunDone: true,
    interview: { step: 0, completed: false },
    galpiMessages: [...state.galpiMessages, ...firstMeetingMessages(ctx)],
  };
}

export function sendToGalpi(state: AppState, text: string, ctx: Ctx, opts: { skipped?: boolean } = {}): AppState {
  const trimmed = text.trim();
  if (!trimmed) return state;
  const mine: GalpiMessage = { id: ctx.newId(), kind: 'text', from: 'me', text: trimmed, at: ctx.now.toISOString() };
  const base: AppState = { ...state, galpiMessages: [...state.galpiMessages, mine] };

  // 갈피가 만남 이야기를 물어본 뒤의 답은 만남 이야기로 받는다 (F2)
  if (state.askingMeetingFeedback) {
    const connectionId = state.askingMeetingFeedback;
    return {
      ...base,
      askingMeetingFeedback: null,
      meetings: state.meetings.map((m) => (m.connectionId === connectionId ? { ...m, feedbackGiven: true } : m)),
      keepsakes: withKeepsake(state, 'firstMeeting', ctx),
      galpiMessages: [
        ...base.galpiMessages,
        galpiText(ctx, '들려줘서 고마워요. 이 이야기는 다음 편지를 고를 때 꼭 참고할게요.'),
      ],
    };
  }

  const result = replyToUser(base, { skipped: opts.skipped ?? false }, ctx);
  return {
    ...base,
    interview: result.interview,
    chapters: [...state.chapters, ...result.newChapters],
    galpiMessages: [...base.galpiMessages, ...result.replies],
  };
}

export function askMeetingFeedback(state: AppState, connectionId: string, ctx: Ctx): AppState {
  if (state.askingMeetingFeedback === connectionId) return state;
  return {
    ...state,
    askingMeetingFeedback: connectionId,
    galpiMessages: [
      ...state.galpiMessages,
      galpiText(ctx, '만남은 어땠어요? 좋았던 것도, 아니었던 것도 다 괜찮아요.'),
    ],
  };
}

export function markGalpiRead(state: AppState, ctx: Ctx): AppState {

}

export function chooseLetterCandidate(state: AppState, letterId: string, candidateId: string): AppState {
  return {
    ...state,
    letters: state.letters.map((l) => (l.id === letterId ? chooseCandidate(l, candidateId) : l)),
  };
}

export function answerLetter(
  state: AppState,
  letterId: string,
  answer: 'accept' | 'pass',
  ctx: Ctx,
  reason?: string,
): AppState {
  const letter = state.letters.find((l) => l.id === letterId);
  if (!letter) return state;

  if (answer === 'accept') {
    const accepted = acceptLetter(letter);
    if (accepted === letter) return state;
    return {
      ...state,
      letters: state.letters.map((l) => (l.id === letterId ? accepted : l)),
      keepsakes: withKeepsake(state, 'firstLetter', ctx),
      galpiMessages: [...state.galpiMessages, galpiText(ctx, '좋아요. 상대분도 좋다고 하면 바로 알려 드릴게요 🙂')],
    };
  }

  const passed = passLetter(letter, reason);
  if (passed === letter) return state;
  const thanks = passed.passReason
    ? '말해 줘서 고마워요. 이 말은 서고에만 남아요.'
    : '괜찮아요. 다음 편지를 쓸 때 참고할게요.';
  return {
    ...state,
    letters: state.letters.map((l) => (l.id === letterId ? passed : l)),
    galpiMessages: [
      ...state.galpiMessages,
      { id: ctx.newId(), kind: 'passedLetter', from: 'system', at: ctx.now.toISOString() },
      galpiText(ctx, thanks),
    ],
  };
}

/** mock 전용 — 상대도 수락한 것으로 만든다. 백엔드가 붙으면 서버 이벤트로 바뀐다 */
export function simulateMutualAccept(state: AppState, letterId: string, ctx: Ctx): AppState {
  const letter = state.letters.find((l) => l.id === letterId);
  if (!letter || letter.status !== 'acceptedWaiting' || !letter.chosenCandidateId) return state;
  const p = letter.profiles[letter.chosenCandidateId];
  const connection: Connection = {
    id: ctx.newId(),
    name: p.name,
    photoUri: p.photoUri,
    letterId,
    ended: false,
    celebrated: false,
    messages: [],
    lastReadAt: null,
  };
  return {
    ...state,
    letters: state.letters.map((l) => (l.id === letterId ? { ...l, status: 'connected' as const } : l)),
    connections: [...state.connections, connection],
    keepsakes: withKeepsake(state, 'firstConnection', ctx),
  };
}

    tasteCards: state.tasteCards.map((c) => (c.id === cardId && c.picked === null ? { ...c, picked } : c)),
  };
}

export function answerLightIntro(
  state: AppState,
  id: string,
  answer: 'accept' | 'pass',
  ctx: Ctx,
  reason?: string,
): AppState {
  const intro = state.lightIntros.find((i) => i.id === id && i.status === 'new');
  if (!intro) return state;
  const trimmed = reason?.trim();
  const next =
    answer === 'accept'
      ? { ...intro, status: 'accepted' as const }
      : { ...intro, status: 'passed' as const, ...(trimmed ? { passReason: trimmed } : {}) };
  return {
    ...state,
    lightIntros: state.lightIntros.map((i) => (i.id === id ? next : i)),
    galpiMessages:
      answer === 'accept'
        ? [...state.galpiMessages, galpiText(ctx, '좋아요. 상대분도 좋다고 하면 알려 드릴게요.')]
        : state.galpiMessages,
  };
}

/** 갈피 빼기 — 그 장은 다시 펼치지 않는다 (갈피 문서 3.6 ①) */
export function removeChapter(state: AppState, chapterId: string): AppState {
  return { ...state, chapters: state.chapters.filter((c) => c.id !== chapterId) };
}

export function setSetting(state: AppState, key: keyof AppState['settings'], value: boolean): AppState {
  return { ...state, settings: { ...state.settings, [key]: value } };

          </Card>
        ) : (
          <Empty text="오늘의 카드는 아직 없어요." />
        )}
        {picked.length > 0 ? (
          <Text style={[styles.collected, { color: t.sub }]}>고른 장면 · {picked.join(' · ')}</Text>
        ) : null}

        <SectionLabel>제가 읽은 당신</SectionLabel>
        {state.interview.completed ? (
          <Card>
            <GalpiText>
              {state.userName} 님은 천천히 걷는 주말을 좋아하고, 조용히 곁에 있어 주는 사람에게 마음이 열리는 분이에요.
              말보다 시간을 함께 보내는 걸로 가까워지는 편이고요.
            </GalpiText>
            <GalpiText style={[styles.sign, { color: t.sub }]}>갈피 드림</GalpiText>
          </Card>
        ) : (
          <Empty text="이야기를 끝까지 들려주면 갈피가 편지를 써요." />
        )}

        <SectionLabel>갈피가 발견한 것</SectionLabel>
        <Empty text="만난 뒤 이야기가 쌓이면 여기에 생겨요." />

        <SectionLabel>갈피가 기억하는 것</SectionLabel>
        {state.chapters.map((c) => (
          <Card key={`memory-${c.id}`}>
            <View style={styles.memoryRow}>
              <Text style={[styles.flex, styles.body, { color: t.ink }]}>{c.title}</Text>
              {confirming === c.id ? (
                <Pressable
                  accessibilityRole="button"
                  onPress={() => {
                    state.removeChapter(c.id);
                    setConfirming(null);
                  }}
                >
                  <Text style={[styles.danger, { color: t.dot }]}>정말 뺄게요</Text>

                </Pressable>
              )}
            </View>
          </Card>
        ))}
        <Text style={[styles.collected, { color: t.sub }]}>갈피를 빼면 그 장은 다시 펼치지 않아요.</Text>
      </ScrollView>
    </Screen>
  );
}
