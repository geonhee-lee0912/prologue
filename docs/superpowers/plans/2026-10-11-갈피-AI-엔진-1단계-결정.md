## 1–6 · 사전 점검 (실행 전)

72. **최종 수정 묶음은 Important 5 + Task 2 +82 판 순서 + Task 17 skip 되돌리기 + 작은 것 다섯(답 없는 JSON 의 위기 신호, '서운' 좁히기, ZWJ 금지 이모지, 먼저 말 걸기 조회 createdAt 만, 시스템 프롬프트 외모 조언 줄) + 문서(컨셉 856행, BACKLOG 줄)** — 개인정보·안전·스펙 쪽이고 하나하나 작다. 나머지 Minor(InfraModule 층, 버튼 메아리, 답한 버튼, 스캔 순서)는 BACKLOG 10 줄로 남겨 작업 폴더를 지운 뒤에도 살아남게 한다 — 틀리면 수정 묶음이 커져 리뷰 면이 넓어진다
73. **Task 14 위기 표시 여는 말은 차지를 통째로 남긴다(lastProactiveAt 지금 + unansweredProactive +1)** — 그날을 쓰고 한 번의 시도로 세어, maxUnansweredProactive 번이면 사용자가 다시 말할 때까지 멈춘다. 리뷰어 안(unansweredProactive 만 되돌림)은 하루 한 번 위기 대화를 국외로 보내는 일이 끝없이 이어진다 — 틀리면 위기 대화 뒤 떠난 사용자는 이틀 뒤부터 먼저 거는 말을 받지 않는다(어차피 위기 표시 여는 말은 보내지 않는다)
74. **Task 7 이모지 금지 목록 방식은 그대로 둔다(리뷰어의 허용 목록 제안은 팔레트가 확정되면 다시 본다)** — ZWJ 빈틈은 이번 묶음에서 막는다 — 틀리면 새 이모지가 나올 때 목록을 늘려야 한다
75. **최종 리뷰의 판단 보류 11줄은 모두 받아들인다** — 이미 규칙·BACKLOG 에 있거나 계획 밖이다. 단 "자유 대화 속 다른 사람 이름이 OpenAI 로 간다"는 BACKLOG 10 "진짜 LLM 켜기 전" 줄로 남긴다 — 비용 없음(문서)
76. **수정 묶음 구현자가 찾은 띄어 쓴 전화 꼴의 같은 누출('+82 10 010 - 1234 - 5678' → '[연락처] - 5678')은 같은 구현자에게 재리뷰 전에 고치게 한다(F7 과 같은 두 판 나누기)** — 개인정보 관문이고 같은 꼴의 검증된 수정이다 — 비용 없음
77. **'서운' 규칙이 물음표로 끝나는 문장을 통째로 면제해 "요즘 안 와서 서운했어요, 잘 지냈어요?" 가 통과하는 것은 받아들인다** — 누구의 부재인지를 정규식이 가를 수 없고(쉼표를 경계로 삼으면 정당한 질문이 막힌다), 죄책감 주지 않기의 주 장치는 먼저 말 걸기 프롬프트다 — 틀리면 드물게 물음으로 끝나는 서운함 표현이 먼저 거는 말로 나갈 수 있다
78. **F7 판 순서의 드문 꼴은 그대로 둔다('+82-10-5010-6789 2024년' → '+82-10-5[연락처]년': 가운데 숫자 하나가 남고 뒤 숫자 묶음을 더 가린다)** — 국제 꼴 번호 뒤에 숫자 묶음이 이어질 때만이고, 남는 숫자 하나로는 사람을 알아볼 수 없으며, 가드를 더하면 '+82010-1234-5678' 이 통째로 안 가려진다(리뷰어 검증) — 틀리면 드물게 뒤 숫자가 더 가려져 보인다(안전한 쪽)
79. **수집 LLM 호출 중 사용자가 갈피 빼기로 X 를 지우면 출처 옮기기가 외래 키(P2003)로 묶음을 되돌리고 다음 수집에서 다시 한다** — 그대로 둔다. 기존 P2025 경합과 같은 결로 손실 없이 다시 돈다 — 틀리면 그 사용자 수집이 한 번 늦어진다
80. **LLM 출력의 다른 부분 문자열 검사(findForbidden, PROACTIVE_BANNED, isStorable 의 자리표시자 includes)는 NFC 로 맞추지 않는다** — OpenAI 출력은 실제로 NFC 이고 사용자 입력 쪽은 F1 이 막았다 — 틀리면 NFD 로 온 모델 출력의 금지 표현을 놓친다(드묾)
