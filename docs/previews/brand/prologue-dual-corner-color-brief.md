# 좌하단·우상단 번짐의 색 조합 비교안

상태 — 운영자는 앞선 세 안이 미완성처럼 느껴진다고 평가했고, 색연필 재질을 유지하면서 좌하단·우상단에 한지에 물방울이 스민 듯 번지는 구도를 제안했다. 이 구도에 동의한 뒤 양쪽 색을 다르게 쓰는 실험을 요청했다. 아래는 이번 라운드의 제작 제안이며 유료 생성 승인은 아직 대기 중이다. 기존 앱은 변경하지 않았다.

## 목적과 방법

- ‘각자의 이야기가 같은 첫 장에 스며든다’는 방향으로 두 모서리의 구도를 잡는다.
- 좌하단은 넓고 풍부하게, 우상단은 조금 작고 가볍게 두며 중앙의 흰 여백과 작은 먹색 로고를 유지한다.
- 이번에는 색 조합을 먼저 비교한다. 두 번짐이 들어간 피치·코랄 PNG 한 장을 생성하고, 미리보기 코드에서 우상단의 표시 색만 바꾼다.
- 같은 원본·크기·위치·알파·로고를 재사용해 형태 차이가 색 비교에 섞이지 않게 한다. 원본 픽셀은 덮어쓰지 않는다.
- 아래 조합은 색 차이가 작은 경우부터 큰 경우까지 비교하기 위한 제안이며 전역 키컬러 확정이 아니다.

| 안 | 좌하단 | 우상단 | 볼 점 |
| --- | --- | --- | --- |
| A | 피치·코랄 | 피치·코랄 | 한 색으로도 두 흐름이 충분히 구분되는지 |
| B | 피치·코랄 | 연한 살구 | 따뜻한 톤을 유지하면서 두 흐름을 구분하는지 |
| C | 피치·코랄 | 아주 연한 라벤더 | 색 차이가 두 이야기를 살리는지, 배경이 강해지는지 |

추천 — B부터 검토한다. 따뜻한 인상을 유지하면서 양쪽 차이를 보여줄 수 있다. 다만 실제 시안에서 구분이 약하면 C와 비교해 판단하며, 결과를 보기 전에 선택을 확정하지 않는다.

## 생성 설정

- 서비스·모델: 힉스필드 GPT Image 2.6 (`gpt_image_2_6`)
- 수량: 배경 PNG 한 장
- 설정: 9:16, 1k, high, 실제 알파 투명 배경
- 참조 이미지: 없음. 기존 먹색 로고는 생성 후 합성한다.
- 표시 변형: 우상단에만 색상 필터를 적용한 비교 화면. 별도 유료 생성은 하지 않는다.
- 견적: 대화에서 이번 라운드의 실시간 견적을 알리고 승인받는다.

## 전체 생성 프롬프트

용도: Prologue 모바일 앱 스플래시의 투명 배경 자산. 좌하단과 우상단에서 각각 한지에 물방울이 떨어져 스며든 것 같은 두 개의 색 번짐을 만들되, 색이 있는 부분에는 섬세한 마른 색연필 입자와 가는 결을 유지한다.
9:16 세로 캔버스, 실제 알파 투명 PNG. 중심에는 앱이 별도 먹색 Prologue 워드마크를 올리므로 글자·로고 없이 배경만 제작한다. 화면 가운데 가로 20~80%, 세로 35~65% 영역은 완전히 투명한 여백으로 남긴다.
구도: 좌하단에는 화면 너비 약 65%, 높이 약 30%에 걸쳐 넓은 번짐 하나가 모서리 바깥에서 이어져 들어온다. 우상단에는 너비 약 45%, 높이 약 22%의 조금 작은 번짐 하나가 모서리 바깥에서 들어온다. 둘은 비대칭으로 대각선 균형을 만들고, 서로 닿지 않는다. 가장자리의 조그만 얼룩에 그치지 말고 색이 모인 내부 영역과 전체 번짐의 형태가 분명하게 보이게 한다.
형태: 한지 섬유를 타고 스민 듯 불규칙하고 둥근 유기적 외곽. 안쪽은 연한 색이 모이고 경계로 갈수록 성긴 색연필 결과 작은 농도 차이를 남기며 자연스럽게 투명으로 사라진다. 가장자리 전체를 균일하게 디지털 블러 처리하지 않는다. 세밀한 연필 입자를 유지하고 굵은 알갱이·털·반복되는 선 무늬로 보이지 않게 한다.
색상: 두 번짐 모두 흰색을 많이 섞은 연한 피치·코랄 #F2CFC5와 #F8E7E0 계열. 안쪽에는 연한 색감이 충분히 모여 완성된 영역으로 보이게 하고, 우상단은 좌하단보다 조금 가볍게 표현한다. 진한 주황·빨강·벽돌색은 쓰지 않는다. 다른 색 조합은 동일한 배경의 표시 색만 조정해 비교하므로 이번 생성에는 새 색을 추가하지 않는다.
분위기: 성인을 위한 모던하고 차분한 편집 디자인, 여유 있는 흰 첫 장과 손으로 남긴 온기. 배경의 대부분은 완전히 투명하게 유지한다. 실제 종이 바탕·섬유를 전체 캔버스에 채우지 않는다.
금지: 종이 사각형·종이 경계·물방울 자체·물 고임·광택·번진 잉크 윤곽선·동심원·하트·구름·날개·꽃·캐릭터·책·편지·비행기·도구·글자·로고·그림자·입체 효과·목업·워터마크. 흰 바탕이나 가짜 체크무늬를 투명 대신 넣지 않는다.

## 비교 화면의 표시 원칙

원본 한 장을 같은 화면 크기로 합성한다. 중앙이 투명한 구도이므로 상단·하단의 표시 영역을 나눠 우상단에만 색상 필터를 적용한다. 위치·범위·원본 알파는 모든 안에서 동일하다. 색상 필터는 비교 화면의 코드로 처리하는 방식까지 운영자에게 알리고 승인받은 뒤 적용한다. 후보는 원본과 분리해 보존하며 실제 앱 적용은 선택 후 진행한다.
