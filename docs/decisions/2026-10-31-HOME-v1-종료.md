# 홈 책방·사서 컨셉(HOME v1) 종료

- 날짜: 2026-10-31
- 결정자: 운영자
- 상태: 종료 승인, 원격 보관 완료

## 결정

7월 HOME v1 코드·설계를 현재 제품에 반영하지 않고 종료한다. 재사용 검토를 다음 작업이나 선행 조건으로 남기지 않는다. 당시 기록은 원격 Git 태그로 보존한다.

2026-09 컨셉 재설정과 이후 현행 설계가 구현 기준이다. 이번 종료는 옛 코드를 main에 병합하거나 현재 서비스 코드·DB·배포 설정을 변경하는 작업이 아니다. 보관된 마이그레이션도 적용하지 않는다.

## 보존한 기록

| 종류                               | 종료한 작업 브랜치             | 원격 보관 태그                 | 커밋      |
| ---------------------------------- | ------------------------------ | ------------------------------ | --------- |
| 코드·미적용 마이그레이션·당시 인계 | `claude/home-v1-wip-2026-07`   | `archive/home-v1-code-2026-07` | `b4b2bd3` |
| 7월 설계와 당시 기획 이력          | `claude/docs-2026-07-unpushed` | `archive/home-v1-docs-2026-07` | `fea6e57` |

두 태그가 기존 브랜치 머리와 같은 커밋을 가리키는지 원격 조회로 확인한 뒤 해당 원격·로컬 브랜치를 삭제했다. 설계 브랜치에는 HOME v1 이전의 기획 이력도 있으므로 전체 이력을 보존했다. 옛 인계의 미결정·재개 안내는 당시 상태이며, 이 종료 결정이 우선한다.

기록은 [코드 보관](https://github.com/geonhee-lee0912/prologue/tree/archive/home-v1-code-2026-07)과 [설계 보관](https://github.com/geonhee-lee0912/prologue/tree/archive/home-v1-docs-2026-07)에서 읽을 수 있다. 내용을 확인하려고 현재 작업 트리에 옛 파일을 복원할 필요는 없다.

## 확인 범위와 다음 순서

- Git 커밋·파일 목록과 원격 태그 보존을 확인했다. 옛 코드 실행·DB 호환성은 검증하지 않았다. 제품에 적용하지 않고 종료하는 작업이다.
- ROADMAP의 HOME v1 항목을 끝남으로 옮긴다. 기존 순서를 유지하면 다음은 갈피 AI 엔진 1단계 남은 일이다.
- 갈피 엔진 구현이나 DB 적용을 이 종료 작업에 포함하지 않는다. 실제 작업 범위와 승인 조건은 해당 현행 설계와 BACKLOG를 따른다.
