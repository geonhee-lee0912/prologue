# 프로필·인증 정보 아키텍처 — 방향 전환 결정 (INFO v1)

- 작성일: 2026-07-06
- 상태: **결정 고정 (창업자 승인)** — 문서 대규모 반영은 다음 단계(§6 목록)
- 범위: 사용자 프로필/인증에서 **어떤 정보를 수집·인증·노출·추천 반영할지**의 전면 재정의.
- 성격: **컨셉 전환.** 기존 "비상품화·인증은 간판 아님" 리드 축을 **"검증 기반 진지한 소개팅 + 리치 프로필"**로 이동.
- 근거 작업: 159개 항목 전수 인벤토리 + 적대 검증 매트릭스(profile-info-matrix 워크플로우). **단, 그 분석은 스펙 항목을 "빼자"로 권장했고, 창업자가 이를 명시적으로 뒤집었다**("검증된 정보 없이 소개글만으로 어떻게 사람을 고르냐"). 이 문서가 그 결정을 고정한다.

## 1. 방향 전환 요약 (INFO 결정)

| ID | 결정 |
|---|---|
| **INFO-1 컨셉 전환** | 프롤로그 = 검증 기반 진지한 소개팅 + 리치 프로필. 리드 축이 "비상품화·이야기 우선" → **"검증된 정보 + 이야기 병행"**. |
| **INFO-2 스펙 6종** | 소득/연봉·자산·학력/학벌·학교명·회사명·키 → **수집 ✅ · 인증 ✅ · 노출 ✅**. |
| **INFO-3 추천 반영** | 위 6종을 **추천 점수 반영 + 필터 사용**. 추천 알고리즘 6개 컴포넌트 재설계 필요. |
| **INFO-4 금지선 유지** | 랭킹·등급·고급회원·"수준 높은 상대"·프리미엄 풀·우선 노출 등 **줄 세우기 프레이밍·기능은 계속 금지**. 정보는 투명, **사람 등급화는 안 함**. |
| **INFO-5 정합성 경계** | INFO-3·4를 동시에 지키는 유일한 형태: **필터 = 사용자 본인 선호 설정**(플랫폼 강제 선별 아님), **점수 = 궁합/선호 부합형**("높을수록 가점" 금지). "고급회원" 라벨·랭킹 UI·스펙 기반 프리미엄 풀 금지. |
| **INFO-6 법적 제약** | 소득·자산·혼인 등 민감정보 수집·인증은 **별도 동의 + 법무 검토 선행** (CLAUDE.md §10 유지). |

> **미해결 가능성 (INFO-5 재확인 포인트):** 창업자가 실제로 "높은 스펙 우대"(status weighting)를 원한다면 그것은 INFO-4 금지선을 일부 푸는 것이며, 이 문서의 궁합형 해석과 달라진다. 그 경우 별도 결정 필요.

## 5. 관통 원칙 (전환 후)

1. **정보는 투명하게 공개·인증한다.** 검증 기반 리치 프로필이 신뢰와 선택 근거를 제공.
2. **단 사람을 줄 세우지 않는다.** 랭킹·등급·고급회원·프리미엄 풀·우선 노출 금지 (INFO-4).
3. **필터 = 사용자 본인 선호 설정. 점수 = 궁합/선호 부합형.** "높을수록 가점" 금지 (INFO-5).
4. **이야기(관계지향·콘텐츠·라이프스타일)는 스펙과 병행하는 핵심 축.** 스펙이 이야기를 대체하지 않는다.
5. **점수 숫자·거절 사유·신고 내용·멤버십 등급은 응답 비노출** (§10/§13 유지).
6. **민감정보(소득·자산·혼인 증빙)는 별도 동의 + 법무 선행** (§10 유지).
