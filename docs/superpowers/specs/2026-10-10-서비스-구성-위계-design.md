# 0. 이 문서의 목적

갈피 캐릭터가 정해진 뒤 앱 전체의 뼈대를 다시 잡았다. 디자인(색·타이포·연출)은 이 뼈대가 확정된 뒤 별도 단계에서 한다.

**출발점이 된 두 문제**

1. 기존 구조(앱 전체가 하나의 대화창)는 서비스가 비어 보인다. 탭을 채워 단단해 보이게 하되 진열은 만들지 않는다
2. 편지가 오기까지 다른 서비스보다 훨씬 오래 걸린다. 그 답답함을 풀고, 앱을 자주 열 이유를 만든다

# 1. 결정 요약

| 항목 | 결정 |
|---|---|
| 내비게이션 | **하단 탭 4개: 갈피 / 대화 / 내 서고 / 설정.** 앱을 열면 갈피 탭 |
| 갈피 탭 | **다마고치형 방.** 갈피가 사는 서고 방이 홈이고, 대화·편지·취향 카드 등은 게이트웨이로 각자 페이지에 들어간다 |
| 대화 탭 | 연결된 사람들과의 메신저 목록. 사람만 있다 |
| 소개 | **두 종류.** 갈피의 편지(메인, 이야기로 고르기) + 가벼운 소개(서브, 사진 중심) |
| 편지의 자리 | **관계를 따라간다.** 편지함은 없다 |
| 매일 열 이유 | 갈피 의식(취향 카드, 태엽), 편지를 쓰는 중 신호, 범위 넓혀 보기, 가벼운 소개 |
| 다른 캐릭터 | 나중에. 서고는 갈피만 읽고, 다른 캐릭터는 자기 방에서 들은 것만 안다 |
| 5번째 탭 | 나중에. 1순위 후보는 "만남" |

# 2. 탭 구조

```
[진입 — 별도 스택, 한 번만]
랜딩(웹) → 동의 3종 → 기본 정보·사진 → 갈피 탭에서 첫 만남

┌────────────┬────────────┬────────────┬────────────┐
│   갈피      │   대화      │  내 서고    │   설정      │
│ (기본 탭)   │            │            │            │
└────────────┴────────────┴────────────┴────────────┘
```

| 탭 | 역할 | 한 줄 |
|---|---|---|
| **갈피** | 관계와 소개 | 갈피가 사는 방. 모든 소개가 여기서 온다 |
| **대화** | 사람과 이어지는 곳 | 서로 수락한 사람과의 대화 |
| **내 서고** | 나를 알아가는 곳 | 내 이야기가 쌓이고 나를 비춰 보는 곳 |
| **설정** | 관리 | 계정, 노출, 결제, 안전 |

**탭에 대한 원칙**: 어떤 탭도 다른 사람을 둘러보는 곳이 되지 않는다(하드룰 1). 추천·탐색·좋아요 목록·지난 소개 모음은 탭이 될 수 없다. 기존 설계(화면 흐름 0.5)가 탭을 피한 이유가 이것이었고, 이 원칙을 지키는 한 탭을 둘 수 있다고 판단을 바꿨다.

# 3. 갈피 탭 — 다마고치형 방

## 3.1 방에서 바로 일어나는 것 (페이지 이동 없음)

- 갈피의 표정·몸짓 (표정 9종, 갈피 문서 3.5). 시간대별 행동은 이후 확장
- **말풍선**: 갈피가 먼저 건네는 한마디. 누르면 대화 페이지에서 그 말에 바로 이어 답한다
- **태엽 감기**, 갈피 눌러 보기 → 반응 (갈피 문서 3.6 ①)
- **상태 한 줄**: 이야기 읽는 중 / 편지 고민 중 / 편지가 왔어요 / 답을 기다리는 편지 + 대기 카운터

## 3.2 게이트웨이

| 누르는 것 | 가는 곳 | 기존 화면 ID |
|---|---|---|
| 💬 이야기하기 / 말풍선 | **갈피와의 대화 페이지** — 인터뷰, 매일 대화, 넘긴 이유, 만난 뒤 | B1~B4, C2, D2, F2 |
| 책상 위 편지 (도착했을 때만 놓인다) | **편지 페이지** — 이야기로 고르기 → 편지 → 수락/넘기기 | D1 |
| 취향 카드 | **둘 중 하나 고르기 페이지** (갈피 의식) | 새로 |
| 가볍게 보기 | **가벼운 소개 시트** — 한 장씩 | 새로 |
| 책장 | 내 서고 탭 | C3, G1 |

**대화가 한 단계 뒤로 가는 손해**는 말풍선으로 메운다. 대화는 매칭 데이터의 원천이므로 갈피가 질문을 먼저 건네고 사용자는 말풍선을 눌러 답하는 흐름을 기본으로 한다.

## 3.3 다마고치에서 가져오지 않는 것 (하드룰 6)

- 배고픔·기분 게이지, 돌보지 않으면 시들거나 시무룩해지는 것
- 돌본 정도에 따라 소개가 빨라지거나 늦어지는 것
- **쌓이기만 하고 줄지 않는다.** 방에 소품이 늘고 갈피의 반응이 풍부해진다

## 3.4 낮과 밤 (디자인 단계 결정, 2026-10-10)

- **화면은 그대로, 방 안만 바뀐다.** 말풍선·버튼·탭의 색과 위치는 시간대와 상관없이 같다. 밤에는 방에 등불이 켜지고 창밖이 어두워지며 갈피가 편지를 쓰거나 존다. 화면 전체가 바뀌면 사용자가 당황한다
- 다크 모드는 시간대가 아니라 기기 설정을 따른다

## 3.5 방 꾸미기와 포인트 (결정, 2026-10-10)

- 활동으로 포인트를 얻고, 포인트로 **소품·스킨을 사서 방에 배치**한다
- **포인트는 활동으로만 얻는다.** 돈으로 사지 않는다
- **포인트를 주는 것**: 인터뷰의 고비(첫 장, 완주), 하루 한 번 취향 카드, 만난 뒤 이야기, 태엽 감기 — 양이 아니라 단계와 의식에 준다
- **포인트를 주지 않는 것**: 메시지 개수·답변 길이(인터뷰 데이터 오염), 넘긴 이유 작성 횟수(성의 없는 이유가 쌓임), 매일 접속·연속 기록(끊기면 벌이 됨, 하드룰 6)
- **포인트와 소품은 소개에 아무 영향이 없다** (하드룰 6)
- **열린 질문**: 포인트와 연결권의 관계 — BM과 포인트 구성을 설계할 때 정한다. 바꿀 수 있게 하면 연결권을 노가다로 모을 수 있어 BM이 무너질 위험이 있다
- **열린 질문**: 소품의 유료 판매 — 가능성은 열어 두되 나중에. 방은 남에게 보이지 않으므로 구매 동기가 약할 수 있다. 캐릭터를 아끼는 마음으로 사는 사례(펫·꾸미기 앱)는 있으나, 보여줄 상대가 생기는 연인 단계(10.5)에서 동기가 커진다

## 3.6 MVP 범위

정지 포즈 몇 개 + 표정 9종 + 방 하나. 시간대별 행동과 소품은 이후 확장. 3D 질감은 에셋 비용이 크다(갈피 문서 3.5 남은 과제).

# 4. 소개 시스템

## 4.1 두 종류의 소개

| | **갈피의 편지 (메인)** | **가벼운 소개 (서브)** |
|---|---|---|
| 언제 | 갈피가 확신할 때 | 갈피가 "괜찮을 수도 있다"고 볼 때 |
| 고르는 기준 | **이야기** | **사진** |
| 형식 | 기준을 넘는 후보가 **두 명이면 이야기 한 줄씩 보고 하나를 고른다.** 고른 쪽만 사진과 편지가 열린다. **한 명뿐이면 기다리지 않고 한 통** | 사진 + 짧은 이유 한 줄. 한 장씩, 시트로 |
| 갈피의 말 | "이 분을 소개하고 싶어요" | "확신은 덜해요. 지은 님 취향을 더 알고 싶어서 보여드려요" |
| 목적 | 만남 | **외모 취향 학습** + 빈도. 여기서 배운 것이 메인의 정확도로 돌아간다 |
| 넘긴 이유 | 자유 입력 (화면 흐름 D2) | 탭 한 번 + 원하면 한마디 |
| 다음 소개 조건 | **지금 편지에 수락하거나 넘기기 전에는 다음 편지가 오지 않는다.** 내가 답하면(수락이든 넘김이든) 잠금이 풀린다. 상대의 답을 기다리는 동안에도 다음 편지는 올 수 있다 | 메인과 따로 움직인다 |
| 만료 | **7일.** 편지에 "일요일까지 열려 있어요"를 적고, 만료 하루 전 갈피가 한 번 말한다. 만료되면 다음 편지를 받을 수 있다 | **그날 자정.** 따로 안내하지 않는다 |
| 노출 | 지금처럼 | **본인이 켜야 나간다 (기본 꺼짐)** |
| 하루 상한 | **TBD** | **TBD** |

## 4.2 왜 이렇게 나눴나

- 이런 소개는 현실적으로 외모 비중이 높다. 갈피가 외모 취향을 배우려면 많이 보여주고 반응을 받아야 하는데, 편지가 드물면 배울 기회도 적다. **가벼운 소개가 외모를 정직하게 떠맡고, 메인은 이야기에 집중한다**
- 다른 서비스가 하루 5명 이상 보여줄 때 우리가 몇 주에 한 통이면, 품질이 좋아도 체감은 "안 온다"다
- **메인을 이야기로 고르는 이유**: 직접 고른 상대를 더 좋아하는 효과(선택 후 선호 변화)는 가져오고, 사진을 나란히 놓으면 외모처럼 비교하기 쉬운 속성에 무게가 쏠리는 문제는 피한다. 고르지 않은 쪽은 사진도 신원도 노출되지 않고 다음 편지에 다시 나올 수 있다
- 사진 블라인드(컨셉 3.8)와의 차이: 사진을 숨기는 게 아니라 누구 이야기를 먼저 들을지 고르는 것이다. 고르면 사진이 바로 열리므로 공개 시점의 이탈 절벽이 없다

## 4.3 가벼운 소개의 선

- 노출은 선택이다. 교사·간호사처럼 노출을 원하지 않는 사람은 메인 편지에만 나간다 (진열되지 않을 권리의 마지막 보루)
- 여러 장을 한 화면에 깔지 않는다. 한 장씩
- 하루 상한이 있다. "최대 N"은 되고 "매일 N명"이라는 약속은 안 된다(하드룰 3). 화면 문구는 "오늘은 여기까지예요"
- 바로가기에 남은 개수를 숫자로 붙이지 않는다

## 4.4 넣지 않은 것과 이유

| 검토한 것 | 넣지 않은 이유 |
|---|---|
| 사람 둘을 나란히 놓고 고르기 | 비교에서 진 사람이 생긴다(상품화). 노출 두 배. 외모 비중 증폭 |
| 기준 미달 후보를 "덜 맞는 분"으로 보내기 | 메인의 기준은 낮추지 않는다. 가벼운 소개는 기준이 다른 별도 형식이고 양쪽 동의가 있을 때만 |
| 공용 서가 (익명 답 읽기 + 밑줄) | 익명 답은 대체로 밋밋해 설렘이 적고, 매력이 떨어진다는 판단 (사용자) |
| 친구를 소개하는 편지 | 사용자 판단으로 제외 |
| 유리병 편지 | 사실상 블라인드 소개팅(컨셉 3.8). 괴롭힘·연락처 교환 통제 어려움 |
| 커뮤니티·익명 게시판 | 다른 사용자가 보이고 운영 부담이 크다 |

# 5. 편지는 관계를 따라간다

편지에는 상대의 사진과 정보가 들어 있다. 편지를 모아 두는 곳이 생기면 그곳이 곧 소개받은 사람들의 목록이 되고, 그것은 진열이다. **편지함을 두지 않는다.**

| 편지 상태 | 어디에 |
|---|---|
| 도착, 아직 답하지 않음 | 갈피 방 책상 위 + 상태 한 줄. 편지 페이지에서 열린다 |
| 서로 수락 | **그 사람과의 대화방 맨 위 "첫 장"으로 고정** |
| 내가 수락, 상대 답 대기 | 갈피 탭에 "답을 기다리는 편지"로 남는다. 상대 쪽 편지의 만료(7일)가 지나면 조용히 닫힌다. 상대가 넘겼는지 만료됐는지 구분해 알리지 않는다 |
| 내가 넘김 | 편지가 닫히고 사진이 사라진다. "넘긴 편지" 한 줄만 남고 다시 열 수 없다 (되돌리기 금지, 화면 흐름 8.2) |
| 만료 | 넘김과 같게 닫힌다. 상대에게 넘김과 구분해 알리지 않는다 |
| 제가 읽은 당신 (리포트) | 사람이 아니라 나에 대한 편지라 내 서고에 보관 |
| 가벼운 소개 | 편지가 아니다. 시트를 닫으면 남지 않는다. 서로 수락하면 그 대화방 첫 장에 사진과 이유 한 줄 |

이름 "프롤로그"와 맞는다 — 편지가 두 사람 대화의 첫 장이 된다.

# 6. 대화 탭

- 서로 수락한 사람과의 대화방 목록. 메신저 형태라 어깨너머로 봐도 소개팅 앱처럼 보이지 않는다
- 안 읽은 수는 나에게만 보인다. 상대 쪽 읽음 표시는 없다 (하드룰 6)
- 대화방 구성: **첫 장(소개 편지)** 고정 → "두 분만의 대화예요. 갈피는 읽지 않아요" 고정 안내 → 대화(E2), 앱 안 통화(E3), 만남 약속(F1) → 메뉴: 연결 끝내기, 차단·신고, 연락처 교환(권하지 않으므로 메뉴 안쪽)
- **끝난 연결은 "지난 대화"로 접혀 내려간다.** 사진은 남지 않고 이름과 첫 장만 남는다. 사람 목록이 쌓여 진열이 되지 않게 한다
- 연결이 없을 때: "아직 연결된 분이 없어요. 갈피가 편지를 쓰면 여기에 대화가 생겨요." 앱을 열면 갈피 탭이 먼저 나오므로 빈 대화 탭은 문제가 되지 않는다

# 7. 내 서고 탭

| 항목 | 내용 |
|---|---|
| **갈피 의식** | 하루 한 번 취향 카드 — 사람이 아니라 장면(데이트 장면, 분위기, 대화 한 문장)을 **둘 중 하나** 고른다. 고르는 재미와 비교 데이터를 얻되 아무도 비교당하지 않는다. 고른 것과 넘긴 것은 매칭 재료(컨셉 5.3). 안 해도 손해 없음 |
| **책장** | 고른 취향 카드와 내 이야기가 쌓인다 |
| **제가 읽은 당신** | 리포트 편지. 매일 대화와 만남 피드백이 쌓이면 갱신 |
| **갈피가 발견한 것** | "좋다고 한 사람과 실제로 대화가 잘 통한 사람은 이런 점이 달랐어요" (컨셉 4.5) |
| **갈피가 기억하는 것** | 내가 들려준 이야기를 보고, 원하는 갈피를 빼서 지운다 (열람·삭제권 대응. 갈피 문서 3.6 ①의 "갈피를 빼면 그 장은 다시 펼치지 않아요") |

# 8. 설정 탭

- 내 정보·사진, **내 편지 미리보기**("상대에게는 이렇게 소개돼요")
- 편지에 담을 조건 정보 허락 관리 (갈피 문서 4장)
- **가벼운 소개에 나가기** 켜기/끄기 (기본 꺼짐)
- **편지 잠시 쉬기** — 연결된 대화 중에도 편지는 오는 것이 기본이고, 쉬고 싶으면 여기서
- 연결권 — 잔여, 구매, 내역
- 알림, 차단·신고(지인 차단 포함)
- 결정 설명 요청 (개인정보보호법 제37조의2, 법적 필수)
- 고객센터·약관, 탈퇴

# 9. 답답함을 푸는 장치 정리

| 다른 앱의 서브 소개가 주는 것 | 우리가 주는 방식 |
|---|---|
| "오늘도 뭔가 왔다"는 기대 | **편지를 쓰는 중 신호** — 실제로 후보를 살필 때만, 신원 없이 ("지은 님처럼 걷는 걸 좋아하는 분이에요"). 결국 쓰지 않게 되면 그렇다고 말한다 / 갈피의 말풍선 / 가벼운 소개 |
| 더 받고 싶을 때의 통제감 | **범위 넓혀 보기** — 사용자가 자기 조건(생활권·나이)을 넓힌다. 갈피의 품질 기준은 그대로 (컨셉 5.4) |
| 고르고 평가하는 재미 | 취향 카드(둘 중 하나), 메인 편지의 이야기 고르기, 가벼운 소개 |

초기 대기가 긴 근본 원인은 서고의 밀도다. 이 장치들은 기다림의 체감을 바꾸지만 밀도를 대신하지는 못한다.

# 10. 다른 캐릭터 (나중에)

**서고 규칙 1을 다듬는다**: 당신의 이야기는 갈피만 읽는다. 다른 친구들은 서고 밖에서 일하고 자기 방에서 들은 것만 안다. 서고의 이야기를 넘겨받지 않는다.

| 역할 | 읽는 것 | 비고 |
|---|---|---|
| 상담 친구 | 자기 방에서 들은 것만. 기록하지 않음 | 오프 더 레코드 공간. "기록하지 않음"은 기술적으로 사실이어야 하고 처리방침에 명시 |
| 만남 도우미 | 약속 시간·장소 | 5번째 탭 "만남"의 주인 후보 |
| 안내 캐릭터 | 개인 정보 없음 | 동의·결제·신고는 여전히 담백한 시스템 문구(갈피 문서 2.6) |

어느 방에서든 위기 신호는 똑같이 안전 안내로 넘어간다. MVP는 갈피만 만든다. 구조는 탭과 대화방이 더 들어와도 흔들리지 않게 짠다.

# 10.5 장기 방향 — 연인 앱으로의 확장

소개팅 앱의 확장으로 **연인이 된 두 사람이 계속 쓰는 앱**으로 발전시킨다. 갈피나 신규 캐릭터가 활동하며 라포를 이어간다.

- 의미: 지금은 연결되면 카톡으로 나가고 끝난다. 남을 이유가 생기면 "만난 뒤 듣는다"(컨셉 4.4)의 학습 루프가 연애 기간까지 이어진다
- **미리 박아 두는 원칙: 연인이 되어도 각자의 서고는 서로에게 열리지 않는다.** 갈피에게 한 말, 다른 사람을 넘긴 이유를 연인이 보게 되면 하드룰 2가 깨지고 지금의 솔직함이 사라진다. 두 사람의 공간은 새로 만들고 서고와 분리한다
- 상세 설계는 나중에. 소품 유료 판매(3.5)는 이 단계에서 다시 본다

# 10.6 디자인 기준 (잠정, 2026-10-10)

화면을 만들면서 실제로 입혀 보고 확정한다.

|---|---|

| 바탕 | 오프화이트(#FBFAF7 근처) 또는 그보다 더 흰색 |
| 파스텔 후보 | 라벤더·버터 / 하늘·살구 / 로즈·올리브 중에서 |
| 주 버튼 색 | 미정 (먹색 / 갈피 초록 / 파스텔 진하게) |
| 글꼴 | 화면은 Pretendard, 갈피의 말풍선과 편지만 명조 계열(시안: 고운바탕) |
| 방의 복잡도 | 방은 액자 한 칸, 반짝임 표시는 한 번에 최대 둘, 방은 비어서 시작해 소품으로 채워진다 |
| 열린 질문 | **갈피의 짙은 초록 카디건이 모노톤·파스텔 화면에서 떠 보이는지.** 화면 쪽을 맞출지(주 버튼을 갈피 초록으로) 갈피를 다시 생성할지 |
