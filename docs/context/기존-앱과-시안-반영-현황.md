# 기존 앱과 시안 반영 현황

확인일 — 2026-11-07. 운영자가 요청한 기존 모바일 앱 기준 대조표다. 모바일 화면·상태 코드, 최근 합의 기록과 HTML 시안을 비교했다. 실제 인증·AI·DB·결제·신고 접수 등의 외부 연결 검증은 별도 과제다.

## 기준과 구분

- 기존 앱은 `apps/mobile`, 로컬 화면은 `http://127.0.0.1:8090/`에서 보는 Expo 모의 실행이다.
- HTML 시안은 `docs/previews/onboarding/`, 로컬 주소는 `http://127.0.0.1:8093/`다. 검토용 예시·입력·상태 전환을 제공한다.
- 이번 대화에서 실제 모바일에 새로 적용한 변경은 갈피 행 → 대화, 사진 → 방 진입 분리와 앱 시작 → 스플래시 → 승인한 서비스 소개 네 장이다. 소개의 시작하기·로그인은 기존 가입·로그인 화면의 해당 영역으로 연결했다. 최신 승인에 따라 기존 스플래시에 장식 없는 3번 `Prologue` 로고도 적용했다.
- 아래 ‘기존 구현’은 작업 전부터 있던 모의 화면·로컬 동작을 포함한다. 화면 존재, 최근 결정 반영, 실제 서버 연결을 각각 확인한다.

## 옛 코드의 재사용을 먼저 확인할 기능

- 신고는 별도 [기존 신고 화면](../../apps/mobile/app/report.tsx)과 API 호출 코드가 있다. 현행 상대 대화 메뉴의 신고·차단은 준비 중이다. 최신 동선·권한·접수 결과를 대조한 뒤 연결한다.
- 탈퇴는 별도 [기존 탈퇴 화면](../../apps/mobile/app/my/j07-withdraw.tsx)과 API 호출 코드가 있다. 현행 설정의 탈퇴 행은 준비 중이다. 최근 개인정보·잔여 연결권 정책과 실제 동작 검증이 필요하다.
- 인증은 별도 [기존 인증 관리](../../apps/mobile/app/my/j03-verifications.tsx)와 가입·OTP 코드가 있다. 일부 옛 서약·얼굴 인증 전제가 남아 있어 현행 설계와 대조한다.

이 화면들은 실제 인증·신고·삭제를 호출해 검증하지 않았다. 소스에서 화면과 호출 코드의 존재를 확인했다.

## 결정이 필요한 내용

- 갈피의 고정형·모델·혼합 여부, 운영 모델, 페르소나·후속 응답과 정보 정리 방식. 기존 앱의 모의 대본은 최종 방식 채택을 뜻하지 않는다.
- 첫 대화에서 채울 프로필 범위·순서·필수 여부와 소개 준비 완료 기준.
- 인증 제공자·사진 검수·조건 증빙, 최종 동의 문안·거부/철회·보관·삭제.
- 상대 선호의 중요도·유연성, 본인이 확인한 제외 기준과 외형 정보 활용.
- 연결권 상품·가격·대화 성립 기준·잔여가 없을 때 처리·환불·복원.
- 신고·차단·종료 후 기록, 통화·약속·연락처 교환·알림의 상세 동작.

## 다음 검토 제안

운영자 요청으로 기존 앱의 스플래시·서비스 소개부터 다시 검토한다. 흰 바탕·먹색 버튼·프리텐다드와 승인한 투명 삽화를 유지한다. 이어지는 가입·동의·본인인증 화면의 상세는 기존 코드를 대조하며 하나씩 의논한다. 기존 홈과 그 이후 화면의 구성을 이번 작업에서 바꾸지 않았다.
