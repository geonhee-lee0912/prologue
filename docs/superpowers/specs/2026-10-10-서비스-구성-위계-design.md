# 0. 이 문서의 목적

갈피 캐릭터가 정해진 뒤 앱 전체의 뼈대를 다시 잡았다. 디자인(색·타이포·연출)은 이 뼈대 위에서 화면을 만들며 확정한다(10.6).

**출발점이 된 두 문제**

1. 기존 구조(앱 전체가 하나의 대화창)는 서비스가 비어 보인다. 탭을 채워 단단해 보이게 하되 진열은 만들지 않는다
2. 편지가 오기까지 다른 서비스보다 훨씬 오래 걸린다. 그 답답함을 풀고, 앱을 자주 열 이유를 만든다

**화면 컨셉의 기준 — 친구가 카톡으로 소개팅을 해주듯이**

컨셉의 출발점은 "친구가 소개팅을 해주듯 갈피가 해준다"(컨셉 4.3)이다. 한국에서 친구가 해주는 소개팅은 처음부터 끝까지 카톡에서 일어난다. 그래서 화면은 **카톡의 익숙한 틀**을 따른다.

| 친구가 해주는 소개팅 (카톡) | 우리 서비스 |
|---|---|
| 평소에 수다 떨기 | 매일 대화 |
| "요즘 어때? 어떤 사람이 좋아?" | 인터뷰 |
| "소개팅 할래? 이런 사람 있어" + 사진 + 몇 마디 | 편지 |
| "해볼게" / "이번엔 패스, 왜냐면…" | 수락 / 넘김 + 넘긴 이유 |
| 친구가 연결해 줌 | 연결된 대화방이 생김 |
| "어땠어?" | 만난 뒤 이야기 |

**v1(다마고치형 방을 홈으로)을 바꾼 이유**: 방 홈은 놀이를 핵심 앞에 세워 "펫 게임인가, 소개팅인가" 하는 정체성의 혼란을 만든다. 다마고치가 사람을 다시 부르는 힘은 "돌보지 않으면 나빠진다"인데 우리는 그것을 하드룰 6으로 뺐으므로, 남는 꾸미기·수집은 에셋을 계속 넣어야 돌아가는 비싼 엔진이다. 반면 "갈피가 나를 기억하고 먼저 말을 거는 것"은 싸고 매일 새로우며, 그 시간이 곧 소개의 재료(컨셉 5.2)가 된다. 다마고치 요소는 버리지 않고 **갈피 프로필(방)과 이모티콘**으로 옮겼다.

| 항목 | 결정 |
|---|---|
| 화면 컨셉 | **카톡의 틀.** 친구 / 대화 / 내 서고 / 설정 |

| 갈피와의 대화 | **하나의 대화방.** 대화 탭 맨 위 고정. 친구 탭·알림·중요한 일 카드에서도 들어간다 |
| 다마고치 요소 | **갈피 프로필 = 갈피의 방.** 표정 9종은 이모티콘으로 |
| 알림 원칙 | **말로 알리고, 장면은 분위기만.** 중요한 일은 글·카드·버튼이 책임진다 |
| 소개 | **두 종류.** 갈피의 편지(메인, 이야기로 고르기) + 가벼운 소개(서브, 사진 중심) |
| 편지의 자리 | **관계를 따라간다.** 편지함은 없다 |
| 자라는 것 | 책장(내 이야기) + 소품(포인트) + 기념품(여정의 순간). 숫자 게이지 없음. 갈피의 변화는 2차에 반드시 |
| 다른 캐릭터 | 나중에. 친구 목록에 추가된다. 서고는 갈피만 읽는다 |
| 5번째 탭 | 나중에. 1순위 후보는 "만남" |

# 2. 탭 구조

```
[진입 — 별도 스택, 한 번만]
랜딩(웹) → 동의 3종 → 기본 정보·사진 → 갈피 대화방에서 첫 만남(인터뷰 시작) → 이후 첫 화면은 친구 탭

┌────────────┬────────────┬────────────┬────────────┐
│   친구      │   대화      │  내 서고    │   설정      │
│ (첫 화면)   │            │            │            │
└────────────┴────────────┴────────────┴────────────┘
```

| 탭 | 역할 | 한 줄 |
|---|---|---|
| **친구** | 갈피의 근황과 중요한 일 | 갈피와 (나중의) 캐릭터들, 그리고 그들의 소식 |
| **대화** | 모든 대화 | 갈피와의 대화(맨 위 고정) + 서로 수락한 사람들 |
| **내 서고** | 나를 알아가는 곳 | 내 이야기가 쌓이고 나를 비춰 보는 곳 |
| **설정** | 관리 | 계정, 노출, 결제, 안전 |

**탭에 대한 원칙**: 어떤 탭도 다른 사람을 둘러보는 곳이 되지 않는다(하드룰 1). 추천·탐색·좋아요 목록·지난 소개 모음은 탭이 될 수 없다. 기존 설계(화면 흐름 0.5)가 탭을 피한 이유가 이것이었고, 이 원칙을 지키는 한 탭을 둘 수 있다고 판단을 바꿨다.

# 3. 친구 탭과 갈피

## 3.1 친구 탭 (첫 화면)

위에서 아래로:

1. **내 프로필** — 누르면 **내 편지 미리보기**("상대에게는 이렇게 소개돼요"). 진열되지 않는다는 안심과, 사진·정보를 다듬을 동기
2. **중요한 일 카드** (있을 때만) — 3.2
3. **친구** — 갈피. 카톡의 상태메시지처럼 갈피의 한마디가 보인다("오늘은 비가 와서 서고가 조용해요 ☔"). 누르면 갈피 프로필(방, 3.6). 나중의 캐릭터도 여기에 추가된다
4. **소식** — 3.3

**연결된 사람은 친구 목록에 넣지 않는다.** 만난 사람들이 친구로 쌓이면 그것이 사람 목록, 곧 진열이 된다. 사람은 대화 탭에만 있다.

## 3.2 중요한 일 카드와 우선순위 — 말로 알리고, 장면은 분위기만

**원칙**: 중요한 일은 글·카드·버튼이 분명하게 알린다. 갈피의 방(프로필)은 그것을 따라 분위기만 바꿀 뿐, 정보를 혼자 들고 있지 않는다. 방을 한 번도 열지 않아도 놓치는 것이 없어야 한다.

- 친구 탭의 중요한 일 카드는 **크게 하나 + 작게 하나까지**. 나머지는 사라지지 않고 갈피 대화방에 남는다
- 같은 순위가 갈피의 **상태메시지**와 **대화방 첫 말**도 정한다
- **사건이 일상보다 먼저다**
- **갈피는 사용자가 안 와서 슬퍼하지 않는다.** 오랜만에 와도 반가워할 뿐이다

| 순위 | 상태 | 카드 / 갈피의 말 | 누르면 |
|---|---|---|---|
| 1 | **서로 수락됨** (한 번만) | "두 분 다 이야기 나눠 보고 싶대요." 첫 기념품이 방에 놓인다 | 그 사람과의 대화방 |
| 2 | **만남 다음 날** | "어제는 어땠어요?" | 갈피 대화방 (만난 뒤 이야기) |
| 3 | **편지 도착, 아직 답 안 함** | "✉️ 갈피가 편지를 썼어요 · 일요일까지 열려 있어요" | 편지 |
| 4 | **인터뷰 이어하기** | "지난번엔 여기까지 이야기했어요." | 갈피 대화방 (이어서) |
| 5 | **편지 고민 중** (진행 신호) | "편지를 쓸지 고민 중인 분이 있어요." | 카드 없음 — 상태메시지와 대화방에서만 |
| 6 | **오랜만에 옴** | "지은 님! 반가워요 ☕" | 카드 없음 |
| 7 | **평소** | 갈피가 기억에서 꺼낸 한마디. 하루 한 번 새로 쓴다 | 카드 없음 |

**2위와 3위**: 만남 다음 날과 편지 도착이 겹치면 만남 이야기를 먼저 묻는다. 만남의 기억은 하루만 지나도 흐려지고 그 이야기가 학습 루프의 핵심이다. 편지는 7일간 열려 있고 작은 카드로 함께 보인다.

**방에 나오지 않는 것**: 상대가 나를 넘긴 일, 편지 만료. 아무 일도 없었던 것처럼 평소다(5장).

## 3.3 소식

카톡의 "친구 소식"처럼, 갈피와 서고와 나에 대한 소식이 올라온다.

| 소식 | 예 |
|---|---|
| 갈피가 프로필을 바꿨어요 | "방에 작은 화분이 생겼어요" + 방 미리보기 |
| 갈피의 서고 일지 | "오늘은 오래된 편지들을 다시 읽었어요. 다들 첫 문장을 제일 오래 고민했더라고요." |
| 오늘의 취향 카드 | 둘 중 하나 고르기 — 사람이 아니라 장면(7장) |
| 가볍게 볼 분이 있어요 | 글만. 사진은 시트를 열어야 보인다 |
| 서고 소식 | 대기 카운터, 새 기능 |
| 내 이야기 | 책장에 새 장이 꽂혔어요, 기념품이 생겼어요 |

**선**

1. **다른 사용자는 소식에 절대 나오지 않는다** (익명이어도). 하드룰 1의 "피드 금지"는 "다른 사용자를 보여주는 피드 금지"다
2. **끝없이 내려가지 않는다.** 오늘의 소식 몇 개만, 지난 소식은 사라진다. 무한 스크롤은 체류 장치이고 KPI(만남)와 맞지 않는다
3. **계속 만들어도 비용이 거의 들지 않는 것만.** AI가 쓰는 갈피 일지, 시간대에 따라 자동으로 바뀌는 프로필, 취향 카드. 사람이 손으로 만드는 콘텐츠에 기대지 않는다
4. 사진이 담긴 소개(가벼운 소개 포함)는 소식에 사진을 싣지 않는다

## 3.4 친구 목록

- 지금은 **갈피 하나**
- 나중에 상담 친구, 만남 도우미, 안내 캐릭터가 친구로 추가된다(10장)
- 각 친구는 프로필(방)과 대화방을 가진다

## 3.5 갈피와의 대화방

**하나의 대화방, 여러 입구**: 대화 탭 맨 위(고정) / 친구 탭의 갈피 프로필 → 대화하기 / 중요한 일 카드 / 알림. 어디로 들어가든 같은 대화가 이어지고, 갈피가 먼저 건넨 말이 있으면 그 말에 바로 답하는 상태로 열린다.

| 대화방 안의 장치 (카톡에 익숙한 것) | 쓰임 |
|---|---|
| **공지 고정** | 답을 기다리는 편지. 만료일을 사실대로 적는다 |
| **공유 카드** | 편지 카드. 누르면 편지 페이지가 열린다 |
| **이모티콘** | 갈피의 표정 9종. 갈피가 이모티콘으로 반응한다 |
| 일반 메시지 | 인터뷰, 매일 대화, 넘긴 이유, 만난 뒤 이야기, 편지를 쓰는 중 신호, 범위 넓혀 보기 |
| 갈피가 건네는 버튼 | "가볍게 볼 분이 있어요 → 열기" → 가벼운 소개 시트 |

**기존 화면 ID가 간 곳**

| 기존 화면 (화면 흐름 설계) | 이제 |
|---|---|
| B1~B4 인터뷰, B3 이어하기 | 갈피 대화방 |
| C1 대기 상태·카운터 | 친구 탭 소식(서고 소식) + 갈피 상태메시지 |
| C2 매일 대화 | 갈피 대화방 |
| C3 리포트 | 내 서고 |
| D1 소개 카드 | 편지 페이지 (갈피 대화방의 편지 카드·중요한 일 카드에서 열림) |
| D2 넘긴 이유 | 갈피 대화방 |
| E1~E3 연결·대화·통화, F1 만남 약속 | 대화 탭의 사람 대화방 |
| F2 만난 뒤 | 갈피 대화방 |
| G 계정 | 설정 |

## 3.6 갈피 프로필 = 갈피의 방

카톡 프로필처럼 배경이 곧 방이다. 다마고치 요소는 여기에 산다.

- **들어가면 갈피가 하던 일을 멈추고 나를 알아본다.** 평소엔 자기 일을 하고 있다 — 아침엔 커피, 낮엔 책 정리, 저녁엔 창밖, 밤엔 등불 아래 편지, 새벽엔 졸음
- **할 수 있는 것**: 대화하기 / 태엽 감기 / 방 꾸미기. 갈피를 눌러 보면 표정 반응
- **방의 물건**: 책장(누르면 내 서고), 창문, 책상, 등불, 그리고 쌓인 소품과 기념품
- **낮과 밤**: 화면의 틀(버튼·글자)은 그대로, 방 안만 바뀐다. 다크 모드는 시간대가 아니라 기기 설정을 따른다
- **반짝임은 숨은 재미에만**: 새 기념품, 처음 보는 소품. 한 번에 최대 둘. 편지 같은 중요한 일에는 쓰지 않는다(3.2)

## 3.7 자라는 것

| 쌓이는 것 | 어떻게 생기나 | 의미 |
|---|---|---|
| **책장 (내 이야기)** | 인터뷰의 고비, 매일 대화의 장이 묶일 때 | 갈피가 나를 아는 만큼. 이것이 곧 소개의 재료 |
| **소품** | 포인트로 산다 (3.9) | 내 취향 |
| **기념품** | **여정의 순간에만** — 첫 편지, 첫 연결, 첫 만남. 돈·포인트로 살 수 없다 | 내가 걸어온 길. 방에서 가장 특별한 물건이 실제 만남에서만 생기므로 다마고치의 동기가 접속이 아니라 만남을 향한다 |

- **숫자 게이지는 두지 않는다.** "친밀도 37" 같은 숫자는 관계를 점수로 만든다. 자라는 것은 방의 모습으로만 보인다
- **갈피의 변화(반응·행동이 풍부해짐)는 2차에 반드시 넣는다.** 처음엔 기념품이 생길 때 갈피가 놓아 주는 장면 정도로 시작한다(에셋 비용)

## 3.8 다마고치에서 가져오지 않는 것 (하드룰 6)

- 배고픔·기분 게이지, 돌보지 않으면 시들거나 시무룩해지는 것
- 돌본 정도에 따라 소개가 빨라지거나 늦어지는 것
- 할 일 목록(체크리스트) — 숙제가 되고 연속 기록 압박으로 흐른다
- **쌓이기만 하고 줄지 않는다**

## 3.9 방 꾸미기와 포인트

- 활동으로 포인트를 얻고, 포인트로 **소품·스킨을 사서 방에 배치**한다
- **포인트는 활동으로만 얻는다.** 돈으로 사지 않는다
- **포인트를 주는 것**: 인터뷰의 고비(첫 장, 완주), 하루 한 번 취향 카드, 만난 뒤 이야기, 태엽 감기 — 양이 아니라 단계와 의식에 준다
- **포인트를 주지 않는 것**: 메시지 개수·답변 길이(인터뷰 데이터 오염), 넘긴 이유 작성 횟수(성의 없는 이유가 쌓임), 매일 접속·연속 기록(끊기면 벌이 됨, 하드룰 6)
- **포인트와 소품은 소개에 아무 영향이 없다** (하드룰 6)
- **열린 질문**: 포인트와 연결권의 관계 — BM과 포인트 구성을 설계할 때 정한다. 바꿀 수 있게 하면 연결권을 노가다로 모을 수 있어 BM이 무너질 위험이 있다
- **열린 질문**: 소품의 유료 판매 — 가능성은 열어 두되 나중에. 방은 남에게 보이지 않으므로 구매 동기가 약할 수 있다. 보여줄 상대가 생기는 연인 단계(10.5)에서 다시 본다

## 3.10 MVP 범위

- 친구 탭: 내 프로필(편지 미리보기), 중요한 일 카드, 갈피, 소식(갈피 일지·취향 카드·서고 소식)
- 갈피 대화방: 공지 고정, 편지 카드, 이모티콘(표정 9종)
- 갈피 프로필: 방 하나 + 정지 포즈 몇 개 + 낮/밤. 태엽 감기
- 나중: 시간대별 행동, 소품 상점과 배치, 갈피의 변화

# 4. 소개 시스템

## 4.1 두 종류의 소개

| | **갈피의 편지 (메인)** | **가벼운 소개 (서브)** |
|---|---|---|
| 언제 | 갈피가 확신할 때 | 갈피가 "괜찮을 수도 있다"고 볼 때 |
| 고르는 기준 | **이야기** | **사진** |
| 형식 | 기준을 넘는 후보가 **두 명이면 이야기 한 줄씩 보고 하나를 고른다.** 고른 쪽만 사진과 편지가 열린다. **한 명뿐이면 기다리지 않고 한 통** | 사진 + 짧은 이유 한 줄. 한 장씩, 시트로 |
| 갈피의 말 | "이 분을 소개하고 싶어요" | "확신은 덜해요. 지은 님 취향을 더 알고 싶어서 보여드려요" |
| 목적 | 만남 | **외모 취향 학습** + 빈도. 여기서 배운 것이 메인의 정확도로 돌아간다 |
| 넘긴 이유 | 자유 입력 (화면 흐름 D2) | 탭 한 번 + 원하면 한마디 |
| 다음 소개 조건 | **지금 편지에 수락하거나 넘기기 전에는 다음 편지가 오지 않는다.** 내가 답하면(수락이든 넘김이든) 잠금이 풀린다. 상대의 답을 기다리는 동안에도 다음 편지는 올 수 있다 | 메인과 따로 움직인다 |
| 만료 | **7일.** 편지에 "일요일까지 열려 있어요"를 적고, 만료 하루 전 갈피가 한 번 말한다. 만료되면 다음 편지를 받을 수 있다 | **그날 자정.** 따로 안내하지 않는다 |
| 노출 | 지금처럼 | **본인이 켜야 나간다 (기본 꺼짐)** |
| 하루 상한 | **TBD** | **TBD** |

## 4.2 왜 이렇게 나눴나

- 이런 소개는 현실적으로 외모 비중이 높다. 갈피가 외모 취향을 배우려면 많이 보여주고 반응을 받아야 하는데, 편지가 드물면 배울 기회도 적다. **가벼운 소개가 외모를 정직하게 떠맡고, 메인은 이야기에 집중한다**
- 다른 서비스가 하루 5명 이상 보여줄 때 우리가 몇 주에 한 통이면, 품질이 좋아도 체감은 "안 온다"다
- **메인을 이야기로 고르는 이유**: 직접 고른 상대를 더 좋아하는 효과(선택 후 선호 변화)는 가져오고, 사진을 나란히 놓으면 외모처럼 비교하기 쉬운 속성에 무게가 쏠리는 문제는 피한다. 고르지 않은 쪽은 사진도 신원도 노출되지 않고 다음 편지에 다시 나올 수 있다
- 사진 블라인드(컨셉 3.8)와의 차이: 사진을 숨기는 게 아니라 누구 이야기를 먼저 들을지 고르는 것이다. 고르면 사진이 바로 열리므로 공개 시점의 이탈 절벽이 없다

## 4.3 가벼운 소개의 선

- 노출은 선택이다. 교사·간호사처럼 노출을 원하지 않는 사람은 메인 편지에만 나간다 (진열되지 않을 권리의 마지막 보루)
- 여러 장을 한 화면에 깔지 않는다. 한 장씩
- 하루 상한이 있다. "최대 N"은 되고 "매일 N명"이라는 약속은 안 된다(하드룰 3). 화면 문구는 "오늘은 여기까지예요"
- 바로가기에 남은 개수를 숫자로 붙이지 않는다

## 4.4 넣지 않은 것과 이유

| 검토한 것 | 넣지 않은 이유 |
|---|---|
| 사람 둘을 나란히 놓고 고르기 | 비교에서 진 사람이 생긴다(상품화). 노출 두 배. 외모 비중 증폭 |
| 기준 미달 후보를 "덜 맞는 분"으로 보내기 | 메인의 기준은 낮추지 않는다. 가벼운 소개는 기준이 다른 별도 형식이고 양쪽 동의가 있을 때만 |
| 공용 서가 (익명 답 읽기 + 밑줄) | 익명 답은 대체로 밋밋해 설렘이 적고, 매력이 떨어진다는 판단 (사용자) |
| 친구를 소개하는 편지 | 사용자 판단으로 제외 |
| 유리병 편지 | 사실상 블라인드 소개팅(컨셉 3.8). 괴롭힘·연락처 교환 통제 어려움 |
| 커뮤니티·익명 게시판 | 다른 사용자가 보이고 운영 부담이 크다 |
| 소개 탭 | "보러 가는 곳"이 되어 진열에 가까워진다. 소개는 갈피가 건네는 사건으로만 온다 |
| 다마고치형 방을 첫 화면으로 (v1) | 0장 참고 |

# 5. 편지는 관계를 따라간다

편지에는 상대의 사진과 정보가 들어 있다. 편지를 모아 두는 곳이 생기면 그곳이 곧 소개받은 사람들의 목록이 되고, 그것은 진열이다. **편지함을 두지 않는다.**

| 편지 상태 | 어디에 |
|---|---|
| 도착, 아직 답하지 않음 | 친구 탭 중요한 일 카드 + 갈피 대화방의 편지 카드와 공지 고정. 편지 페이지에서 열린다 |
| 서로 수락 | **그 사람과의 대화방 맨 위 "첫 장"으로 고정** |
| 내가 수락, 상대 답 대기 | 갈피 대화방 공지에 "답을 기다리는 편지"로 남는다. 상대 쪽 편지의 만료(7일)가 지나면 조용히 닫힌다. 상대가 넘겼는지 만료됐는지 구분해 알리지 않는다 |
| 내가 넘김 | 편지가 닫히고 사진이 사라진다. 대화방에는 "넘긴 편지" 한 줄만 남고 다시 열 수 없다 (되돌리기 금지, 화면 흐름 8.2) |
| 만료 | 넘김과 같게 닫힌다. 상대에게 넘김과 구분해 알리지 않는다 |
| 제가 읽은 당신 (리포트) | 사람이 아니라 나에 대한 편지라 내 서고에 보관 |
| 가벼운 소개 | 편지가 아니다. 시트를 닫으면 남지 않는다. 서로 수락하면 그 대화방 첫 장에 사진과 이유 한 줄 |

이름 "프롤로그"와 맞는다 — 편지가 두 사람 대화의 첫 장이 된다.

# 6. 대화 탭

- **맨 위에 갈피 고정.** 사람 줄과 다르게 생긴다(캐릭터 아바타, 다른 배경). 안 읽은 수는 숫자 대신 **점 하나** — 갈피는 먼저 말을 거는 일이 잦아 숫자가 쌓이면 그 자체가 압박이 된다
- 그 아래 **서로 수락한 사람과의 대화방.** 메신저 형태라 어깨너머로 봐도 소개팅 앱처럼 보이지 않는다
- 사람 대화방의 안 읽은 수는 나에게만 보인다. 상대 쪽 읽음 표시는 없다 (하드룰 6)
- 사람 대화방 구성: **첫 장(소개 편지)** 고정 → "두 분만의 대화예요. 갈피는 읽지 않아요" 고정 안내 → 대화(E2), 앱 안 통화(E3), 만남 약속(F1) → 메뉴: 연결 끝내기, 차단·신고, 연락처 교환(권하지 않으므로 메뉴 안쪽)
- 같은 목록에 있어도 갈피 대화방과 사람 대화방은 서로 다른 방이라는 것이 분명해야 한다(컨셉 5.6)
- **끝난 연결은 "지난 대화"로 접혀 내려간다.** 사진은 남지 않고 이름과 첫 장만 남는다. 사람 목록이 쌓여 진열이 되지 않게 한다
- 갈피가 늘 있으므로 대화 탭은 비어 보이지 않는다

# 7. 내 서고 탭

| 항목 | 내용 |
|---|---|
| **책장** | 내 이야기가 장 단위로 꽂힌다(3.7). 고른 취향 카드도 모인다 |
| **취향 카드** | 하루 한 번(소식에도 뜬다) — 사람이 아니라 장면(데이트 장면, 분위기, 대화 한 문장)을 **둘 중 하나** 고른다. 고르는 재미와 비교 데이터를 얻되 아무도 비교당하지 않는다. 고른 것과 넘긴 것은 매칭 재료(컨셉 5.3). 안 해도 손해 없음 |
| **제가 읽은 당신** | 리포트 편지. 매일 대화와 만남 피드백이 쌓이면 갱신 |
| **갈피가 발견한 것** | "좋다고 한 사람과 실제로 대화가 잘 통한 사람은 이런 점이 달랐어요" (컨셉 4.5) |
| **갈피가 기억하는 것** | 내가 들려준 이야기를 보고, 원하는 갈피를 빼서 지운다 (열람·삭제권 대응. 갈피 문서 3.6 ①의 "갈피를 빼면 그 장은 다시 펼치지 않아요") |

# 9. 답답함을 푸는 장치 정리

| 다른 앱의 서브 소개가 주는 것 | 우리가 주는 방식 |
|---|---|
| "오늘도 뭔가 왔다"는 기대 | **갈피가 먼저 거는 말**과 상태메시지, **소식**, **편지를 쓰는 중 신호**(실제로 후보를 살필 때만, 신원 없이 — "지은 님처럼 걷는 걸 좋아하는 분이에요". 결국 쓰지 않게 되면 그렇다고 말한다), 가벼운 소개 |
| 더 받고 싶을 때의 통제감 | **범위 넓혀 보기** — 사용자가 자기 조건(생활권·나이)을 넓힌다. 갈피의 품질 기준은 그대로 (컨셉 5.4) |
| 고르고 평가하는 재미 | 취향 카드(둘 중 하나), 메인 편지의 이야기 고르기, 가벼운 소개 |

초기 대기가 긴 근본 원인은 서고의 밀도다. 이 장치들은 기다림의 체감을 바꾸지만 밀도를 대신하지는 못한다.

# 10. 다른 캐릭터 (나중에)

**서고 규칙 1**: 당신의 이야기는 갈피만 읽는다. 다른 친구들은 서고 밖에서 일하고 자기 방에서 들은 것만 안다. 서고의 이야기를 넘겨받지 않는다.

다른 캐릭터는 **친구 탭의 친구로 추가**되고, 각자 프로필(방)과 대화방(대화 탭)을 가진다.

| 역할 | 읽는 것 | 비고 |
|---|---|---|
| 상담 친구 | 자기 방에서 들은 것만. 기록하지 않음 | 오프 더 레코드 공간. "기록하지 않음"은 기술적으로 사실이어야 하고 처리방침에 명시 |
| 만남 도우미 | 약속 시간·장소 | 5번째 탭 "만남"의 주인 후보 |
| 안내 캐릭터 | 개인 정보 없음 | 동의·결제·신고는 여전히 담백한 시스템 문구(갈피 문서 2.6) |

어느 방에서든 위기 신호는 똑같이 안전 안내로 넘어간다. MVP는 갈피만 만든다. 구조는 친구와 대화방이 더 들어와도 흔들리지 않게 짠다.

# 10.5 장기 방향 — 연인 앱으로의 확장

소개팅 앱의 확장으로 **연인이 된 두 사람이 계속 쓰는 앱**으로 발전시킨다. 갈피나 신규 캐릭터가 활동하며 라포를 이어간다.

- 의미: 지금은 연결되면 카톡으로 나가고 끝난다. 남을 이유가 생기면 "만난 뒤 듣는다"(컨셉 4.4)의 학습 루프가 연애 기간까지 이어진다
- **미리 박아 두는 원칙: 연인이 되어도 각자의 서고는 서로에게 열리지 않는다.** 갈피에게 한 말, 다른 사람을 넘긴 이유를 연인이 보게 되면 하드룰 2가 깨지고 지금의 솔직함이 사라진다. 두 사람의 공간은 새로 만들고 서고와 분리한다
- 상세 설계는 나중에. 소품 유료 판매(3.9)는 이 단계에서 다시 본다. 두 사람이 함께 쓰는 방이 생기면 방이 다시 주인공이 될 수 있다
