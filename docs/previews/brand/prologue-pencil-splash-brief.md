# 스플래시 색연필 그라데이션 구성안

상태 — 운영자가 배경 한 장의 생성·적용을 승인하며 진한 코랄 대신 연한 코랄 기반 톤을 요청했다. 해당 톤으로 질감을 생성해 기존 앱 A01 왼쪽 아래에 적용했다. 로고 표시 상자는 가로 224에서 196, 높이 61에서 54로 줄였고 먹색·3번 글자 모양을 유지했다. 실제 웹에서 휴대폰·PC 배치와 온보딩 이동을 확인했다. 실기기와 OS 시작 화면은 미확인이다.

힉스필드에서 생성한 원본의 알파를 유지했다. 연한 피치·코랄의 연필 결만 일부에 있고 나머지는 투명하다. 배경을 장식용으로 분리해 화면 읽기 대상과 입력 영역에서 제외했다. 실제 앱에서 중앙 로고·흰 여백을 유지하고 질감은 왼쪽 아래에만 보이게 했다.

## 적용한 배치

- 흰 바탕과 먹색 Prologue 로고를 유지한다. 로고는 기존 3번 글자 모양 그대로다.
- 코랄색의 색연필 질감이 화면 한쪽 아래에서 조금 올라오고, 중앙과 대부분의 화면은 흰 여백으로 남는다.
- 위치는 왼쪽 아래다. 배경 자산을 로고와 분리해 앱에서 위치·크기·농도를 조정한다.
- 배경 PNG에는 글자나 로고를 넣지 않는다. 앱의 실제 로고 컴포넌트 앞뒤로 질감 자산만 배치한다.
- 키컬러의 최종 색과 전역 적용 범위를 이번 요청만으로 확정하지 않는다. 현재 검토 중인 코랄을 시안의 기준색으로 삼는다.
- 모델·프롬프트·수량·비용을 알린 뒤 운영자의 생성·적용 승인을 받았다. 연한 톤 요청을 반영한 견적도 같음을 재확인했다.

## 생성 설정

- 서비스: 힉스필드
- 모델: GPT Image 2.6 (`gpt_image_2_6`)
- 결과: PNG 한 장, 실제 알파 투명 배경
- 비율과 품질: 1:1, 1k, high
- 참조 이미지: 없음
- 비용: 대화에서 현재 견적 확인
- 용도: 앱의 흰 바탕 위에 겹쳐 놓는 별도 코너 질감

## 전체 프롬프트

용도: 모던한 모바일 앱 스플래시의 일부에 겹쳐 놓을 추상적인 색연필 그라데이션 질감 PNG 한 장. 로고와 글자는 앱에서 별도로 표시하므로 이미지에 넣지 않는다.
주요 요청: 흰색을 많이 섞은 연한 피치·코랄 톤을 색연필로 부드럽게 여러 번 겹쳐 칠한 듯한 그라데이션. 색연필의 고운 입자와 가느다란 결이 살짝 보인다. 디지털로 매끈하게 흐린 면이나 수채화 번짐보다 마른 색연필의 섬세한 결을 표현한다.
색상: 코랄 계열은 기준으로만 참고한다. 진한 #C8603C를 직접 보이게 쓰지 말고 흰색을 많이 섞은 매우 연한 피치·코랄 #F4D3C8에서 #FAEAE3 정도의 톤으로 표현하며, 색연필 층이 투명으로 사라지게 한다. 진한 주황·빨강·벽돌색 부분이나 다른 색 계열은 추가하지 않는다.
구성: 정사각형의 투명한 캔버스. 물감이나 종이 덩어리 같은 피사체를 그리지 말고, 왼쪽 아래에서만 연필색이 살짝 올라오는 불규칙하고 부드러운 질감 패치를 만든다. 색이 가장 보이는 곳도 은은하며, 위와 오른쪽으로 갈수록 완전한 투명으로 사라진다. 캔버스 대부분은 빈 투명 공간으로 유지한다. 나중에 앱의 흰 바탕 위에 얹고 중심에 작은 먹색 로고를 둘 수 있어야 한다.
제약: 배경은 실제 알파 투명. 종이 사각형, 종이의 바깥 가장자리, 사진, 글자, 로고, 편지, 비행기, 하트, 캐릭터, 반짝임, 입체 효과, 테두리, 목업, 선명한 기하학 도형을 넣지 않는다. 색연필 결은 색이 있는 부분에만 나타나고 투명 영역에는 종이나 바탕 질감을 채우지 않는다.

## 확인과 후속 작업

투명 영역·연필 결·연한 색감과 흰 바탕 위의 합성을 확인했다. 실제 앱의 휴대폰·PC 웹에서 작아진 로고의 중앙 배치, 두 이미지 로딩과 온보딩 이동을 확인했고 타입 검사도 통과했다. 이후 화면을 보며 질감의 범위·위치·농도를 의논한다. 실제 키컬러 토큰과 다른 화면에 대한 적용은 별도 결정이다. 원본을 바꾸지 않고 배치에서 조절할 수 있는 사항과 추가 생성이 필요한 사항을 구분한다.
