# C안의 하늘색·원형 번짐 테스트

상태 — 운영자가 C안의 방향을 채택하고 우상단을 하늘색으로 바꾸는 색상 테스트와 번짐을 더 원형에 가깝게 만드는 형태 테스트를 요청했다. 색상 테스트는 기존 원본을 재사용해 완료했다. 원형 편집은 기존 원본을 참조하는 새 라운드로 모델·프롬프트·견적을 준비했으며 비용 승인 전이라 제출하지 않았다. 실제 앱은 아직 바꾸지 않았다.

## 완료한 색상 테스트

- [라벤더와 하늘색 비교 이미지](2026-11-07-sky-color-test.png)
- [반응형 비교 보드](prologue-sky-color-test.html)
- 개별 화면: [기준 C](2026-11-07-sky-color-test-a.png) · [하늘색](2026-11-07-sky-color-test-b.png)
- 원본: [공통 코랄 PNG](../../../apps/mobile/assets/brand/splash-studies/04-dual-corner-peach.png)

같은 원본·같은 화면 크기와 로고를 유지했다. 좌하단은 그대로 두고 우상단의 표시 색만 `hue-rotate(190deg) saturate(.55)`로 바꿨다. 기존 C의 필터는 `hue-rotate(285deg) saturate(.55)`다. 두 화면의 390×844 크기와 196×54 로고, 이미지 로딩, PC·휴대폰 표시와 화면 오류 없음을 확인했다. 추가 유료 생성은 없다. 이전 블루 제외 논의와 별개로 이번 하늘색 테스트는 운영자의 최신 명시적 요청이며 전역 키컬러 확정을 뜻하지 않는다.

## 원형 편집 제안

현재 번짐의 여러 볼록한 돌기와 오목한 굴곡을 줄여, 한 방울이 스민 큰 원호처럼 보이게 한다. 경계에는 작고 불규칙한 번짐과 연필 결을 남긴다. 정확한 기하학 원이나 딱딱한 테두리는 만들지 않는다. 원본의 질감·색·상대 크기·두 모서리 구도를 유지하도록 참조 편집을 요청한다.

| 비교 | 형태 | 우상단 색 |
| --- | --- | --- |
| 기준 C | 기존 번짐 | 연한 라벤더 |
| 색상만 변경 | 기존 번짐 | 연한 하늘색 |
| 형태만 변경 | 더 원형인 번짐 | 연한 라벤더 |
| 두 변화 결합 | 더 원형인 번짐 | 연한 하늘색 |

원형 편집 한 장을 만든 뒤 같은 코드 색상 필터로 두 조합을 비교한다. 마지막 두 화면은 아직 생성 전이다.

## 생성 설정

- 서비스·모델: 힉스필드 GPT Image 2.6 (`gpt_image_2_6`)
- 수량: 참조 편집 PNG 한 장
- 설정: 9:16, 1k, high, 실제 알파 투명
- 입력: 기존 공통 코랄 PNG에 해당하는 완료된 생성 결과. 참조 없이 새로 그리지 않는다.
- 견적: 대화에서 이번 라운드의 실시간 견적을 알리고 승인받는다.
- 로고: 기존 먹색 원본을 별도 합성한다.

## 전체 편집 프롬프트

편집 대상: 이미지 1은 이전에 만든 Prologue 스플래시 배경의 코랄 원본이다. 이 배경의 투명 캔버스·색연필 질감·색감·두 모서리 구도는 유지하고, 두 번짐의 외곽 형태만 더 원형에 가깝게 수정한다.
변경할 부분: 좌하단과 우상단의 번짐을 각각 큰 물방울 하나가 한지에 스며든 듯한 둥근 형태로 단순화한다. 현재 외곽의 여러 볼록한 덩어리와 오목한 굴곡을 줄여, 각 번짐의 전체 윤곽이 하나의 큰 원호로 읽히게 한다. 정확한 기하학 원이나 원 테두리를 그리는 것이 아니라 거의 원형인 얼룩의 경계에만 작고 섬세한 불규칙함을 남긴다.
유지할 부분: 좌하단은 넓고 우상단은 조금 작고 가벼운 비대칭 관계, 원본에 가까운 차지 면적과 모서리 밖으로 이어지는 배치, 색이 모인 내부와 경계로 갈수록 사라지는 농도, 연한 피치·코랄 계열과 섬세한 마른 색연필 입자. 질감을 굵게 확대하거나 새 무늬를 추가하지 않는다.
두 색 번짐은 양쪽 모서리 바깥에서도 이어지는 모습이다. 서로 만나지 않고 중앙에 넓은 투명 여백을 남긴다. 중앙에는 앱이 작은 먹색 로고를 별도 합성할 것이므로 가로 20~80%, 세로 35~65% 구역은 비워 둔다.
출력: 원본과 같은 9:16 세로의 실제 알파 투명 PNG. 원본처럼 두 번짐 모두 연한 피치·코랄로 유지한다. 라벤더와 하늘색은 이후 비교 화면에서 우상단에만 표시 색을 바꾸므로 이번 편집에서 추가하지 않는다.
금지: 글자·로고·흰 배경 채우기·종이 사각형·바깥 테두리·불투명 종이 질감·원 테두리·동심원·물방울 물체·하트·꽃·구름 모양의 여러 둥근 돌기·캐릭터·광택·입체 효과·디지털로 매끈한 원형 그라데이션·워터마크.
