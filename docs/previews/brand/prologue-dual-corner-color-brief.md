# 좌하단·우상단 번짐의 색 조합 비교안

상태 — 운영자는 앞선 세 안이 미완성처럼 느껴진다고 평가했고, 색연필 재질을 유지하면서 좌하단·우상단에 한지에 물방울이 스민 듯 번지는 구도를 제안했다. 양쪽 색을 다르게 쓰는 실험과 원본 한 장 생성·코드로 표시 색을 바꾸는 방법을 승인했다. 이번 라운드의 배경 한 장 생성과 세 색 조합의 비교 화면을 완성했다. 최종 색 선택은 대기 중이며 기존 앱은 변경하지 않았다.

## 목적과 방법

- ‘각자의 이야기가 같은 첫 장에 스며든다’는 방향으로 두 모서리의 구도를 잡는다.

- 이번에는 색 조합을 먼저 비교한다. 두 번짐이 들어간 피치·코랄 PNG 한 장을 생성하고, 미리보기 코드에서 우상단의 표시 색만 바꾼다.

## 비교 화면의 표시 원칙

원본 한 장을 같은 화면 크기로 합성했다. 상단·하단의 표시 영역을 나눠 우상단에만 색상 필터를 적용했다. 위치·범위·원본 알파는 모든 안에서 동일하다. A는 색상 필터가 없고, B는 `hue-rotate(22deg)`, C는 `hue-rotate(285deg) saturate(.55)`다. 하단은 모두 같은 원본과 표시 설정을 유지한다. 이 방법까지 운영자의 승인을 받았고 후보는 원본과 분리해 보존했다. 실제 앱 적용은 선택 후 진행한다.
