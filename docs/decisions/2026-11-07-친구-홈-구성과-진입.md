# 친구 홈 구성과 진입

상태 — 운영자 확정, 2026-11-07.

## 화면 순서

홈은 기존 카카오톡형 친구 목록 구조로 만든다.

1. 내 프로필
2. 중요한 일
3. 친구 목록
4. 소식

중요한 일과 소식은 항목이 있을 때 표시한다. 친구 목록에는 갈피와 서비스 캐릭터가 들어간다. 연결된 상대는 대화 탭에서 만난다.

## 누르는 곳과 목적지

| 누르는 곳 | 목적지 |
| --- | --- |
| 내 프로필 | 내 소개·편지 미리보기 |
| 갈피 행 | 기존 갈피 대화 이어가기 |
| 갈피 사진 | 갈피의 프로필·방 |
| 중요한 일 | 해당 편지·대화·만남 화면 |
| 소식 | 해당 갈피·내 이야기 콘텐츠 |

친구 행과 사진은 서로 독립된 링크로 구현한다. 화면 골격 시안도 이 합의를 기준으로 검토하며 구조 변경은 먼저 제안하고 의논한다.
